# WeRelay 文档导航

这里按“先使用、再理解、后开发和发布”的顺序整理文档。除 `README.md` 这个 GitHub 约定入口外，文档目录和文件统一使用清晰的中文名称；代码目录、协议名和产品名保留原名。

## 第一次使用

1. [项目介绍](使用指南/项目介绍.md)：先理解 WeRelay 解决什么问题，以及哪些 Agent 能继续电脑上的真实任务。
2. [从 GitHub 安装与更新 WeRelay](使用指南/GitHub源码安装与更新.md)：从公开源码构建本地安装包，并理解为什么不需要 npm 公共包。
3. [Agent 安装与配置](使用指南/Agent安装与配置.md)：安装所需 Agent、完成登录并启动 WeRelay。
4. [5 分钟启用局域网移动网页](使用指南/局域网移动网页快速开始.md)：没有公网服务器时完成首次密码设置和手机端到端验收。
5. [运行配置](使用指南/运行配置.md)：查看环境变量、数据目录、后台启动方式和 DeskRelay → WeRelay 迁移说明。
6. [公网 Relay Agent 配置与验收](使用指南/公网Relay配置与验收.md)：可直接交给用户 Agent 执行的服务器部署、验收和回滚 Runbook。
7. [问题排查](使用指南/问题排查.md)：处理微信、终端、网页、Relay 和安装问题。

## 文档维护约定

- 面向普通用户的内容优先使用中文和可直接执行的步骤。
- 一个主题只保留一个事实真源；其他文档通过链接引用，不复制整段规则。
- 改名或移动文档时，必须同时修复 README、AGENTS、CONTRIBUTING、SECURITY、源码提示、测试和版本说明中的路径。
- 中文版本记录是面向用户的主说明，英文版使用 `-英文.md` 后缀。
- 文档不得记录真实服务器地址、本地任务 ID、访问令牌、运行日志或未审查截图。
