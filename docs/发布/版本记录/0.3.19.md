# WeRelay 0.3.19

发布日期：2026-10-21

## 仓库与隐私整理

- 开源程序与品牌官网分开维护，官网文案、演示资料和专用制作工具不再随程序源码及安装包分发。
- 手机任务台、微信连接、公网中继、自建部署示例和使用说明完整保留，安装和使用程序不需要取得官网源码。
- 测试示例中的个人用户名已替换为通用示例，并补充检查，防止私有官网资料再次进入公开版本。
- 文档增加了开源程序与私有官网的清晰边界，方便后续开发与维护。

## 安全维护

- 更新了一项底层组件，修复特定网址可能绕过静态文件访问限制的问题。当前未发现 WeRelay 使用受影响的服务路径，也没有因此遭到攻击的证据。
- 不改变任务、消息、审批或连接方式，无需修改现有配置。

## 使用说明

- 本版包含仓库资料整理和底层安全补丁，产品功能与 0.3.17 相同；无需为此重新登录、配对或迁移任务。
- 本次只发布 GitHub 版本，不自动安装、不重启电脑端或公网服务；现有运行版本保持不变。

## 已知限制

- 本次整理不改写历史提交，也不替换旧版本安装包；旧版非敏感演示资料仍可追溯。
- 0.3.17 已说明的微信回复上下文限制、实时连接长期观察和其他未完成验收项继续适用。
- 尚未经过体验验收的新功能不包含在本版中。
