# WeRelay 0.3.26

更新日期：2026-10-30

## 这次更新

- Pi Desktop 没有开启原生控制接口时，现在可以准备专用连接插件；在桌面端安装并授权后，手机继续使用原来的任务，不会另开一个命令行任务。
- 修复任务结束后仍被旧发送状态挡住、无法继续输入的问题。电脑已确认收到消息时，网页会及时解除等待；响应迟迟未返回时保留原消息与附件，用原编号核对，不自动重复发送。
- 新增 Android vivo 系统通知的服务端接入，可登记、更新和清理设备推送标识。尚未配置厂商凭据时保持关闭，不影响原有网页和微信。
- 修正系统通知的公网地址匹配和原任务定位；审批通知不发送命令正文。

## 升级说明

- 网页刷新一次即可使用最新界面，无需重新配对微信。
- Pi Desktop 首次连接若提示尚未接入，请运行 `werelay-pi-desktop-enable`，按提示在桌面插件管理中安装并授权；不会自动重启应用或授予免审权限。
- vivo 系统通知需要匹配的 Android 客户端及厂商配置。本次只更新 WeRelay 程序和公网任务台，没有安装手机 App 或开启厂商推送。

## 已知限制

- Pi Desktop 插件目前仅支持 macOS/Linux；不确定是否收到消息时会明确提示，不新建替代任务。真实桌面、微信和附件收发由你更新后自行体验。
- vivo 通道尚未完成真实凭据及真机联调；当前运营通知受厂商 7:00–23:00 及频率限制，不保证夜间补发，也未实现跨通道提醒去重。
- 此前偶发的中继断开后自动恢复现象，本次没有宣称解决。
