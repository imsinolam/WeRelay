# WeRelay 0.3.23

发布日期：2026-10-30

## 这次更新

- 更新通信依赖，修复安全检查发现的问题；不改变已有登录、配对和原任务。
- Pi Desktop 在 Windows 上会明确说明暂不支持，避免把无法验证的本机凭据当成安全连接。其他支持平台保持原来的权限保护。

- 从本版开始，版本号统一按末位递增，不再区分体验版与正式版。电脑、任务台和 GitHub 使用同一版本，方便判断是否已经更新。
- 手机发送图片和排队消息后，更准确地确认电脑是否已经收到，减少重复显示、一直等待确认，以及迟到结果把已送达消息重新显示的问题。
- 放大任务菜单的点击区，增加操作图标；切换终端时先保留任务缓存，减少列表闪空，列表顺序更贴近最近实际对话。
- 增加独立的 Pi Desktop 入口，继续电脑端现有任务；微信可用 `/pi-d`，不区分大小写。Pi 命令行和 Pi Desktop 保持为两个清晰入口，不另开替代对话。
- Codex 正在回复时可以先选下一轮模型；Pi 可以连接原窗口的模型控制。网页也能读取支持终端尚未发送的文字草稿，避免已有草稿被静默覆盖。
- ClawBot 任务列表增加网页入口，操作指引更简洁；普通任务列表默认显示更多任务，减少读取失败后的重复检查。
- 统一聊天正文、图片、排队卡片和输入框的界面实现，保留原任务、草稿与模型设置方式。

## 升级说明

- 无需重新登录、重新配对或迁移任务。网页若仍显示旧界面，可刷新。
- Pi 已打开的旧窗口需在任务结束后执行 `/reload`，或正常重新打开，才能加载新版扩展；更新不会强制关闭窗口。
- Pi Desktop 需要先开启并认证本机控制接口；不可用时明确提示，不会改用其他终端替代。
- Agent 与 ClawBot 的真实收发、审批和回复回推由你部署后自行体验，本次不自动发送测试消息。

## 已知限制

- 中继连接仍观察到周期性断开后通过 HTTPS 保底、再恢复 WSS 的现象。基础检查时设备在线，但不能因此认定长期稳定性已解决。
- 微信主动通知仍依赖微信认可的回复上下文；长时间未互动后，可能需要先发一条普通消息。
- Pi Desktop 的审批与待输入问题仍需在桌面端处理；多设备同时发送同一草稿仍不承诺完全没有竞态。
- 本次仅提供 Android 共用网页资源与签名更新的接入基础，不包含 Android 安装包或已启用的签名资源发布。
