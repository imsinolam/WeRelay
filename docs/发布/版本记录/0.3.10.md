# WeRelay 0.3.10

发布日期：2026-09-11

## 这次更新

- 手机上打开公网任务台会更快看到内容：服务器会提前准备好终端列表、任务看板和最近任务的消息，页面打开时直接显示已有结果，不再先空白等待。
- 每条 AI 回复下方会显示完成时间，跨天时会写成“昨天 18:30”或“8 月 30 日 18:30”，方便判断某条回复是刚刚完成的还是更早的。
- DeepSeek Harness 的模型菜单在存在多个模型来源时改为两级选择：先选来源，再选具体模型；只有一个来源时仍直接列出模型，操作方式和以前一样。
- 微信消息发送结果无法确认时，WeRelay 会暂停自动重发并明确提示核实，不再可能把同一条通知重复发出。

## 修复的问题

- **修复了任务台会让电脑“掉线”的问题。** 之前网页每隔几秒读取任务看板时，会同步遍历各个终端的历史会话目录；会话一多，这一步会长时间占满主线程，导致手机显示“电脑不在线”、网页打不开、微信也收不到回复，而电脑上看起来一切正常。现在同样的读取会在短时间内复用结果，并发请求合并成一次，不再反复占用。
- **修复了重启后长时间不可用的问题。** 之前每次启动都会把运行时目录里的每个文件重新设置一遍权限，并且反复与旧版本目录逐项比对；文件积累到上万后，启动要等好几分钟才能恢复服务。现在权限正确时不再重复设置，旧目录比对也只做一次，启动明显加快。
- 网页上刚发出的消息不会在真实记录出现后重复显示，发送过程中也不会出现同一条消息两处渲染。
- 任务已经结束时，消息末尾的等待动画会及时停止；任务仍在处理时继续显示。

## 升级说明

- 升级后无需额外操作，重启 WeRelay 即可。
- 从 0.3.9 或更早版本升级会自动沿用现有配置、登录状态和任务记录，不需要重新登录或重新配置。
- 如果微信完成通知提示需要新消息，请先在微信里给 ClawBot 发送一条普通消息以刷新会话。

## 已知限制

- Windows 上有个别 WorkBuddy 桌面连接相关的自动化用例被暂时跳过（该桌面端只有 macOS 版本），不影响 macOS 和 Linux 上的实际使用。
- 如果运行时目录里再次堆积大量文件（例如把发布备份放在其中），启动仍会比平时慢一些；建议把备份放在运行时目录之外。
