# WeRelay 0.3.17 体验候选

整理日期：2026-10-20

> 此候选已完成代码整合和自动检查，待安装到电脑端与公网 Relay 后进行真实体验验收；不是 GitHub 正式版本。

## 可体验的变化

- 微信通知继续显示对应任务编号，长回答分段后也能知道该回复属于哪个任务。
- 微信恢复连接时，最近三分钟内完成的通知自动尝试发送；更早但未超过一小时的通知先询问，回复“推送”或“补发”后再补发。超过一小时的旧通知不再打扰你。
- Pi 可通过同一个已连接原窗口新建任务；新建前可以读取可用模型，不需要先选择一条旧任务。没有原窗口或窗口有未发送内容时会明确提示，不另开隐藏对话。
- 手机输入区用动态圆球区分发送中、运行中与停止中；电脑离线时保留清楚的状态提示。
- 电脑与公网中继可优先使用实时连接，不可用时退回原来的连接方式。
- 增加微信新版本提醒：发现 GitHub 发布正式新版本后，提示当前版本、可用版本和更新说明。不自动安装，不重启服务。
- 任务看板卡片缩短标题并压缩垂直间距，一屏可以更快浏览更多任务。
- 正在运行、等待审批或等待输入的任务不会再被“最近”页误显示为已完成。

## 尚待体验确认

- 本机与公网需要安装同一份候选产物后才能确认这些变化在线生效。
- 新提醒能力需要先安装到电脑端，之后才会自动提示后续版本。旧版不会因 GitHub 更新自动获得这项功能。
- 微信提醒仍需要有效的回复上下文；暂时发不出时会稍后重试，收到你的真实消息后也会重试。
- 新的公网连接方式需要完成真实公网证书、代理与睡眠恢复验收；Pi 新建和手机视觉变化也需要实机确认。
