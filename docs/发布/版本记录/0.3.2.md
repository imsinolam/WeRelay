# WeRelay 0.3.2

发布日期：2026-08-23

## 这次更新

- 现在从移动网页或 ClawBot 进入 WorkBuddy 任务时，会直接连接电脑上同一个 WorkBuddy 桌面任务，手机和电脑继续共享同一段对话。
- 可以在移动端继续发送消息、处理权限确认和停止任务；结果仍会回到原来的 WorkBuddy 任务，不再另外创建一份隐藏会话。
- 选择已有 WorkBuddy 任务时，WeRelay 会优先准确打开并连接该任务，避免误接到其他任务。

## 修复的问题

- 修复移动端消息虽然执行成功，却没有同步显示在 WorkBuddy 桌面窗口中的问题。
- 修复 WorkBuddy 已经打开但连接尚未准备好时，WeRelay 可能错误重启应用或悄悄改用另一条会话的问题。现在会保留原任务并明确提示连接状态。
- 修复重新连接已有任务时，旧回复可能被误当成本次新回复的问题。

## 升级说明

- 请同时升级电脑端 WeRelay 和公网 Relay，并安全重启现有服务。
- 已有微信登录、网页访问密码、设备配对和任务记录无需重新配置。

## 已知限制

- WorkBuddy 桌面任务接力目前仅支持 macOS，并要求电脑上已安装、登录且运行可接入的 WorkBuddy 版本。
- 如果 WorkBuddy 正在升级、启动或暂时无法连接，WeRelay 会保留原任务并提示稍后重试，不会自动切换到另一条会话。
