# WeRelay 0.3.27

Updated: 2026-10-31

## Changes

- Recover task short-link registration promptly after a stalled network request. A new task-list or notification request retries without waiting behind an old background delay.
- Require a valid registration acknowledgement; proxy login pages and other unexpected responses cannot produce a falsely confirmed link.
- Keep clear failure guidance without changing the original task, message content, or WeChat pairing.

## Upgrade

No pairing or configuration changes are required. Existing task links remain valid.

## Limitations

Network outages and expired WeChat reply contexts may still prevent delivery. Live Agent and ClawBot acceptance is performed by the user after installation.
