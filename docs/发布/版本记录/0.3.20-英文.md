# WeRelay 0.3.20

Release date: 2026-10-22

## What changed

- Viewing the task list in WeChat now includes one concise reminder when older task results are still waiting to be pushed, so you can decide whether to resend them.
- WeRelay can now discover the new DeepSeek Harness desktop application. The task-list guide also explains how to restore WeChat notifications after they have been paused.

## Problems fixed

- The same older results no longer trigger repeated WeChat reminders when the count changes, you turn a page, or the program restarts. Newly arrived results are mentioned separately on the next task-list view.
- A reminder is attached only after the full task list has been sent successfully. An incomplete list or failed reminder is not marked as delivered.
- Older results no longer appear unexpectedly during background recovery or ordinary chat. Results older than one hour stop waiting to be resent.
- A reminder only says that results are waiting; it does not mark the result body as delivered. The body is sent only after you explicitly reply with the resend command.

## Upgrade notes

- Restart the desktop WeRelay daemon and the public relay after upgrading so the new reminder rules take effect immediately.
- No new login, pairing, or task migration is required. Existing tasks and messages remain available.
- If proactive WeChat notifications are temporarily unavailable, send ClawBot an ordinary message in WeChat as explained in the task-list footer.

## Known limitations

- Proactive WeChat notifications still depend on WeChat accepting the current reply context. After a long period without interaction, you may need to send a message first to refresh it.
- Results that remain undelivered for more than one hour are discarded and will not reappear later.
