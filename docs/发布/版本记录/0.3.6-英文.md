# WeRelay 0.3.6

Release date: 2026-08-27

## Fixed problems

- Fixed the local web app, device-online status, and message delivery becoming unresponsive after the mobile web app switched to a Codex task with a very long history.
- WeRelay now reads only the recent tail and newly appended content instead of replaying the entire history. The original task identity, latest reply, and completion delivery remain unchanged.

## Upgrade notes

- Users who installed 0.3.5 should upgrade directly to 0.3.6.
- Upgrade both the desktop WeRelay installation and the public Relay, then restart the existing services safely.
- Existing WeChat login, web password, device pairing, task history, and short links do not need to be configured again.

## Known limitations

- Opening a task with a very long history still loads older messages in pages when requested, but this no longer blocks device connectivity or new message delivery.
- New remote actions cannot run while the desktop Agent or public Relay is offline.
