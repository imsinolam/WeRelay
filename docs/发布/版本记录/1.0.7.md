# WeRelay 1.0.7

发布日期：2026-11-18

## 这次更新

- 设置页新增「巡检记录」，可以按时间查看近期的自动巡检结果；同一天保留最新一份，默认展开最近一次，其余可按需打开。
- 巡检记录只展示问题概况、处理状态和建议的下一步，不包含聊天内容、原始报错或本机路径；手机网页也能查看。
- 切换终端时，选中终端的图标周围会显示绿色呼吸边框，便于确认正在连接哪个终端；完成后提示会自动消失，减少动画干扰。
- 系统开启「减少动态效果」时，切换提示保持静止，不会持续闪烁。

## 升级说明

本机程序和公网 Relay 一并更新后，重新打开手机网页即可使用。访问密码、巡检数据、消息来源授权和原任务历史保留，无需重新设置。

## 已知限制

- 巡检记录是只读摘要；没有新错误不代表所有任务都没有失败，报告会注明本次检查覆盖范围。
- 微信通知仍受微信认可的回复上下文限制，遇到发送保护提示时可向 ClawBot 发送一条新消息后再观察。
- 真实手机、Agent 与 ClawBot 使用体验由用户确认。
