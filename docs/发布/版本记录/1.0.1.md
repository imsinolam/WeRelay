# WeRelay 1.0.1

发布日期：2026-11-07

## 这次更新

- 在手机上输入较长的内容时，输入框不会再突然缩回去；中文输入法拼写期间，文字、光标和滚动位置也会保持稳定。
- 长段落的末尾可以正常看到，编辑中间内容时也不会被自动拉回底部。
- 新建任务时，模型列表会更快显示，并优先使用已经读取过的可用选项；切换不同终端时，不会误用另一个终端的模型选择。
- 如果当前连接方式不支持修改模型，页面会直接说明，不会显示一个实际没有生效的选择。

## 升级说明

本机后台程序和公网 Relay 都需要更新。手机网页重新打开后会载入新版本。已有微信配对、任务历史和访问密码继续保留，无需重新安装 Agent，也不需要重新配置终端。

## 已知限制

- 能否选择模型仍取决于终端和当前连接方式；不支持时页面会明确提示。
- 微信通知需要微信认可的回复上下文；长时间未互动后，可能需要给 ClawBot 发一条消息恢复。
- 真实 Agent 与 ClawBot 的收发体验由用户自行确认。
