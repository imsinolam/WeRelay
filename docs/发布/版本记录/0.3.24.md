# WeRelay 0.3.24

更新日期：2026-10-30

## 这次更新

- 手机任务台连接不到电脑终端时，会在输入框上方保留清楚的提示和“重试”按钮，不再让提示一闪而过。重试时保留当前任务、草稿和待发送消息。
- 设置页新增“消息记录”，可以按 ClawBot、网页任务台、终端、时间和交付状态筛选，查看排队、发送、重试和收件确认过程，并导出当前筛选结果。
- 新增消息数量、失败、排队和重试等统计。统计只涵盖当前保留和筛选范围，不把重试重复计为新消息，也不把“已提交”误当成任务已经完成。
- 可以暂停记录、调整文字保存范围和保留期限，或只清空诊断记录，不影响原任务和待发送队列。
- 修复消息已经提交或排队后，因为后续通知失败而被错误显示为发送失败的问题。

## 升级说明

- 不需要重新登录或配对，已有任务保持不变。手机网页如果仍显示旧界面，可刷新一次。
- 消息记录默认在电脑私有目录保存经过常见敏感内容处理的简短摘要，最多保留 30 天、5000 条，并设有容量限制；可在“记录与隐私设置”中调整或关闭。
- 摘要和导出结果仍可能包含消息中写入的路径或个人信息，请在分享前自行检查。关闭此处记录不会删除 Agent 自己的会话或既有运行日志。

## 已知限制

- 启用前的 ClawBot 历史不会补录；网页只能导入尚在待发送箱中的历史快照，不能据此推算全部历史累计。
- 原终端未提供真实收件回执时，记录只显示“已提交”或“已排队”，不冒称已经送达。
- 中继连接此前仍有短暂断开后恢复的现象，本次没有将其列为已修复。
- 真实 Agent 与 ClawBot 的收发、审批和回复回推，由你更新后自行体验，本次不自动发送测试消息。
