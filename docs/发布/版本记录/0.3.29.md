# WeRelay 0.3.29

更新日期：2026-10-31

## 这次更新

- 微信任务列表底部的网页入口现在直接打开任务看板，不会误进入列表中的某条任务。
- 手机侧栏使用可左右滑动的 Agent 图标栏，完整显示名称，并清楚标识当前选择；长名称与屏幕边缘的显示更自然。
- 一并带来近期任务台改进：消息记录与统计、按项目筛选和原地预览，连接重试提示保持可见。
- Pi Desktop 可通过专用插件连接原任务；任务结束后网页能及时恢复输入，未确认消息保留原编号与附件，减少重复发送。
- 网络卡顿后的任务短链接会及时重试，并确认可用后再发出；新增可选 Android 系统通知接入，未配置时保持关闭。

## 升级说明

网页刷新即可载入新界面，无需重新配对微信。Pi Desktop 首次使用连接插件时仍需用户自行安装并授权；Android 系统推送需要匹配客户端及厂商配置。

## 已知限制

- 实际网络中断或微信回复上下文失效时仍可能暂时无法发送，本次更新不保证消除所有连接异常。
- Android 厂商推送尚未完成真实凭据及真机联调；没有配置时不会启用。
- 真实 Agent、微信收发和审批由用户更新后自行体验，本次发布不代为发送测试消息。
