# WeRelay 0.3.5

发布日期：2026-08-27

## 这次更新

- ClawBot 的最近任务列表现在会稳定显示任务来自哪个终端、属于哪个项目，查找和切换任务时更容易确认目标。
- DeepSeek Harness 在界面和消息中统一简称为 DSH，常用入口仍可使用 `/deepseek` 或 `/dsh`。
- 手机网页会合并同一轮中重复出现的运行进展，保留最新状态，减少反复刷出相同提示。
- 多条暂未送达的完成通知会整理成更容易阅读的汇总，恢复微信连接后更快看清哪些任务已经完成。

## 修复的问题

- 修复切换终端时过早显示成功的问题；WeRelay 现在会先确认目标终端确实可用，失败时保留原来的终端和任务。
- 修复部分已经打开的 WorkBuddy 无法按用户主动操作重新接入的问题。
- 修复 DSH Desktop 因本机访问设置返回拒绝连接时无法恢复的问题；只有用户明确切换到 DSH 时，WeRelay 才会在本机安全范围内尝试修复并重新连接。
- 修复任务列表、终端状态和搜索结果中的名称与项目归属显示不一致的问题。

## 升级说明

- 请同时升级电脑端 WeRelay 和公网 Relay，并安全重启现有服务。
- 已有微信登录、网页访问密码、设备配对、任务记录和短链接无需重新配置。
- 本次升级不需要迁移任务；如果某个桌面终端正在阻止重启，请先保存该终端中的未完成内容，再从网页或 ClawBot 重新切换。

## 已知限制

- DSH 和 WorkBuddy 的自动恢复只会在用户明确切换终端时执行；后台读取任务不会擅自修改设置或重启桌面应用。
- 桌面 Agent 或公网 Relay 离线时，移动网页只能查看已经缓存的内容，恢复连接前不能执行新的远程操作。
