# WeRelay 0.3.22-preview.20261029.1

体验候选日期：2026-10-29

## 这次更新

- 切换终端时保留侧栏任务缓存，减少列表闪空；终端按最近实际消息排序，单纯查看任务不再改变顺序。
- 新增独立的 Pi Desktop 入口，直接连接电脑端现有任务；与 Pi 命令行入口分开，不另开一份对话代替。需要先在 Pi Desktop 开启本机控制接口。
- ClawBot 的任务列表增加网页入口，任务操作提示更简洁。
- 减少任务读取失败时的重复检查；已知无法接收的消息不再反复自动提交，原内容仍保留。
- Codex 正在回复时也可以选择下一轮使用的模型；Pi 模型控制可连接已经接入的原窗口。
- 为 Android 壳共用同一套任务台提供资源导出和签名更新出口。本次不包含 Android 安装包，也没有启用签名资源发布。

## 使用说明

- 不需要重新登录或配对，已有任务保持不变。
- Pi 已打开的旧窗口需在任务结束后执行 `/reload`，或正常重新打开，才能加载更新后的扩展；升级不强制关闭正在运行的窗口。
- 部署后由你亲自验收 Agent 和 ClawBot 的收发、审批及回复回推；部署 Agent 仅检查服务、网页与连接基础状态，不自动发送验活消息。

## 已知限制

- Pi Desktop 需要提供并启用受认证的本机控制接口；审批和待输入问题仍需在桌面端处理。接口不可用时会直接提示，不启动其他终端替代。
- Android 的安装、签名密钥与真机体验属于独立交付；未配置资源更新包时，更新出口保持未启用。
- 本次包含上一候选的纯文字草稿同步和 Pi 运行状态改进；多设备同时发送同一草稿仍不承诺无竞态。
- 微信主动回推仍受有效回复上下文限制。已有 Codex 桌面接收状态及目录读取异常没有因此被认定修复，实际使用请反馈。
- 这是体验候选，尚未作为 GitHub 正式版本发布。
