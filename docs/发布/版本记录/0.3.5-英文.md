# WeRelay 0.3.5

Release date: 2026-08-27

## What changed

- ClawBot's recent-task list now consistently shows which terminal and project each task belongs to, making task lookup and switching easier to verify.
- DeepSeek Harness is now consistently abbreviated as DSH in the interface and messages. Both `/deepseek` and `/dsh` remain available.
- The mobile web app merges repeated progress updates from the same turn and keeps the latest state, reducing duplicate status noise.
- Multiple completion notices that could not be delivered immediately are grouped into a clearer summary when the WeChat connection recovers.

## Fixed problems

- Fixed terminal switching being announced before the target terminal was actually ready. WeRelay now verifies the target first and preserves the previous terminal and task if switching fails.
- Fixed some already-open WorkBuddy installations failing to reconnect after an explicit user action.
- Fixed DSH Desktop being unable to recover when local access settings caused a rejected connection. WeRelay only attempts the local repair after the user explicitly switches to DSH.
- Fixed inconsistent terminal names and project labels across task lists, terminal status, and search results.

## Upgrade notes

- Upgrade both the desktop WeRelay installation and the public Relay, then restart the existing services safely.
- Existing WeChat login, web password, device pairing, task history, and short links do not need to be configured again.
- No task migration is required. If a desktop terminal prevents a restart, save unfinished work there before switching again from the web app or ClawBot.

## Known limitations

- Automatic recovery for DSH and WorkBuddy only runs after an explicit terminal switch. Background task reads do not change settings or restart desktop applications.
- When the desktop Agent or public Relay is offline, the mobile page can only show cached content; new remote actions cannot run until the connection recovers.
