# 0.3.13 体验更新（2026 年 9 月 13 日，第五次）

这是一份体验候选，尚未发布为 GitHub 正式版本。

## 这次改善

- 手机发送消息遇到网络波动时，会先确认原任务是否已收到；已送达的消息会自动消除失败提示，不再因为回执晚到而误导重复发送。
- 发送结果暂不明确时，会继续核对原任务，不擅自另开任务，也不盲目重复发送。原消息和附件会保留。
- 进入任务后，侧边栏会自动找到当前任务；手机打开菜单后也能看到它。正常刷新不会把你手动滚动的位置拉回去。
- 未送达的旧完成通知超过六小时后不再补发，避免恢复连接时收到大量过时通知。

## 使用提示

无需重新配对。已打开的页面可刷新后体验。微信会话凭据失效时，仍可能需要在微信给 ClawBot 发一条新消息来恢复回推；本次并不取消这项保护。

## 仍需观察

网络异常后的迟到回执恢复、真实微信回推和长时间在线情况仍需结合实际使用持续观察。
