# WeRelay 1.0.2

Release date: 2026-11-10

## What's new

- When the mobile keyboard opens, the composer follows the visible area instead of being covered. Closing the keyboard or leaving the composer restores the normal layout.
- Height, scrolling and caret placement are handled more natively by the mobile browser, making typing, long-press selection and drag scrolling feel closer to the system text field.
- Text being composed by Chinese and other input methods cannot be sent accidentally. Backgrounding the page clears pending keyboard layout work so returning to the page does not jump.
- Pinch zoom and minor viewport changes are no longer mistaken for an opened keyboard, and the page no longer shrinks to an invalid height.

## Upgrade

Update both the local background program and the public Relay, then reopen the mobile page. Existing WeChat pairing, task history, access passwords and terminal settings are retained; no Agent reinstall is required.

## Known limitations

- Mobile browsers differ in how they report virtual keyboards and visible viewports. Without those signals, the page keeps its normal layout.
- WeChat notifications require an accepted reply context. After a long idle period, send ClawBot a fresh message if needed.
- The user confirms real mobile typing, input-method behavior, and Agent/ClawBot messaging after upgrading.
