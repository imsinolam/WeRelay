# WeRelay 0.3.14

发布日期：2026-09-24

## 这次更新

- 手机网页和微信现在可以查看电脑上 Pi Agent 的原有任务，并把文字消息送进同一个可见的 Pi 窗口；回复仍留在原任务，不会暗中另开一条对话。
- 已经打开 Pi 的人可以在电脑上启用 WeRelay 扩展，再在原窗口输入 `/reload` 接入；不必为了连接手机重新创建任务。

## 修复的问题

- Pi 已经回复后，手机网页不再一直显示“正在同步运行状态”。
- 手机网页向 Codex 发送消息和读取最新回复更可靠；某项终端检查暂时失败时，任务列表不会被误当成空列表。

## 升级说明

- 由 WeRelay 打开的 Pi 窗口会自动接入；此前独立打开的 Pi 窗口需要先运行 `werelay-pi-enable`，然后在**同一个窗口**输入 `/reload`。
- 不需要迁移或复制 Pi 的任务文件。如果原窗口已经关闭，不能把重新打开的窗口称作此前仍在运行的窗口。

## 已知限制

- Pi 目前支持文字任务与停止运行；图片、审批回传和从微信执行 Pi 自己的斜杠命令暂不支持。
- Windows 暂不能安全接管已经打开的普通 Pi 窗口，也不会自动恢复可能被另一个进程使用的 Pi 旧任务。
- 电脑睡眠、网络中断或微信长时间未使用后，首次恢复可能需要短暂等待；微信发送上下文失效时，需要先给 ClawBot 发一条新消息。
