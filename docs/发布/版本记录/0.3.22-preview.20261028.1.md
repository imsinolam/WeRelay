# WeRelay 0.3.22-preview.20261028.1

体验候选日期：2026-10-28

## 这次更新

- 在网页打开同一任务时，可以接着编辑电脑端尚未发送的文字草稿，不必重新复制。
- 网页已经输入或修改的内容会保留，不会被随后读取的电脑端草稿覆盖；电脑端草稿变化时会提示核对，避免误发旧内容。
- 保留上一候选的改进：Pi 准备回复时及时显示“运行中”，停止或准备失败后清除标记；ClawBot 默认每页显示 15 条任务。

## 使用说明

- 不需要重新登录或配对，已有任务保持不变。
- 已打开的 Pi 窗口需要等任务结束后执行 `/reload`，或正常重新打开，才能加载新的草稿与状态同步能力；升级不会强制关闭 Pi。

## 已知限制

- 草稿同步目前仅支持能够安全读取的 Codex 纯文字草稿，以及提供编辑器接口的 Pi 原窗口；其他终端、富文本和附件不自动导入。
- 两台设备同时发送同一草稿的极端并发场景尚未完成验收；发送前请核对原任务进度。
- 上一候选验收时，Codex 专用任务未能取得桌面接收状态，原任务收发与微信最终回复回推仍需复核，不以读取到历史记录作为发送成功。
- 这是体验候选，尚未作为 GitHub 正式版本发布。
