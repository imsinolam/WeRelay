# WeRelay 1.0.0

Release date: 2026-11-05

## What's new

- WeRelay enters the stable 1.0 release line. WeChat, the mobile task board and the computer continue the same real task, using one version number for each update.
- Choose the model and reasoning effort for the next mobile message. The selection remains visible until the computer confirms it.
- Messages, activity and approval changes update the mobile page automatically. Recently used tasks are prepared in the background to reduce switching delays.
- Open related child tasks in a read-only preview at the end of the parent conversation without changing the active task or discarding drafts.
- More consistent headers, Agent icons, new-task handoff and short-link entry to tasks and the board.

## Fixes

- Model choices no longer jump back to old values before confirmation, and loading task settings does not block the rest of the page refresh.
- New-task and reconnect flows track the real task and explain connection state more accurately.
- Internal child tasks stay within their parent relationship instead of appearing as ordinary independent tasks; approvals retain their actual routing.

## Upgrade

Update and reconnect the local background program, then refresh the mobile page. Existing WeChat pairing, task history and access passwords are retained. The move to 1.x does not change the data format or workflow.

## Known limitations

- Desktop synchronization, model switching and approvals depend on the Agent capabilities listed in the README. The computer must remain on, connected and running WeRelay.
- Child-task previews require reliable relationship records from the computer; failed reads can be retried.
- WeChat notifications still require an accepted reply context. After a long idle period, send ClawBot a fresh message if needed.
- The user confirms real Agent and ClawBot messaging and approvals after upgrading.
