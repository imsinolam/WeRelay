# WeRelay 1.0.2

发布日期：2026-11-10

## 这次更新

- 手机键盘弹出时，输入区域会跟着可见范围上移，不再被键盘挡住；收起键盘或离开输入框后，页面会恢复原来的布局。
- 输入框的高度、滚动和光标位置更多交给手机浏览器自己处理，输入、长按选择和拖动滚动更贴近系统原生手感。
- 正在使用中文等输入法组词时，不会误把未完成的内容发送出去；页面切到后台时也会清理键盘布局，避免返回后突然跳动。
- 缩放页面或屏幕尺寸轻微变化时，不会再误判成键盘弹出，页面高度也不会出现异常收缩。

## 升级说明

本机后台程序和公网 Relay 都需要更新。手机网页重新打开后会载入新版本。已有微信配对、任务历史、访问密码和终端设置均保留，无需重新安装 Agent。

## 已知限制

- 不同手机浏览器对虚拟键盘和可视区域的通知方式仍有差异；如果某个浏览器没有提供这些信息，页面会继续使用原有的正常布局。
- 微信通知需要微信认可的回复上下文；长时间未互动后，可能需要给 ClawBot 发一条消息恢复。
- 真实手机输入、中文输入法和 Agent/ClawBot 收发体验由用户自行确认。
