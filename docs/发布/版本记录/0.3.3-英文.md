# WeRelay 0.3.3

Release date: 2026-08-23

## What changed

- Messages sent from the mobile web app or ClawBot now continue in the already open Codex Desktop task after recent desktop-app updates, instead of remaining unconfirmed.
- A successful mobile send is tied to the single turn actually accepted by the desktop task, preventing duplicate sends and silent replacement tasks.
- When Codex finishes, WeRelay waits for the complete reply to reach the task history before reliably forwarding the final result to WeChat.

## Fixed problems

- Fixed mobile and ClawBot messages timing out without entering the original task after a Codex Desktop upgrade.
- Fixed final WeChat replies being missed when the task transcript was still settling immediately after completion.
- Fixed pending completion retries being cleared too early when delivery could not yet be confirmed.

## Upgrade notes

- Upgrade both the desktop WeRelay installation and the public Relay, then restart the existing services safely.
- Existing WeChat login, web password, device pairing, short links, and task history do not need to be configured again.
- If a message sent before the upgrade says that receipt was not confirmed, check the original desktop task before deciding whether to resend it.

## Known limitations

- Codex Desktop must remain signed in and the original task must still be readable. If the desktop app is updating, closed, or temporarily unavailable, WeRelay preserves the original task and asks you to retry later instead of creating a replacement task.
