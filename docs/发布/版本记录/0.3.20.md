# WeRelay 0.3.20

发布日期：2026-10-22

## 这次更新

- 微信里查看任务列表时，如果还有较早的任务结果没有自动推送，会附带一次简洁提醒，方便你决定是否补发。
- 新版 DeepSeek Harness 桌面应用可以被 WeRelay 正常发现，任务列表也增加了微信通知暂停后的恢复说明。

## 修复的问题

- 相同的一批较早结果不再因为数量变化、翻页或程序重启在微信里反复提醒；新的结果只会在下一次查看任务列表时单独提醒。
- 只有任务列表完整发送成功后才会附带提醒；列表没有发完或提醒没有送达时，不会把提醒误记成已经发送。
- 较早结果不会在后台恢复或普通聊天时突然出现；超过一小时的旧结果会停止补发。
- 提醒只说明还有结果待确认，不会把结果正文当作已送达；只有你明确回复“推送”后才会补发正文。

## 升级说明

- 升级后建议重启电脑端 WeRelay 和公网 Relay，让新版提醒规则立即生效。
- 无需重新登录、重新配对或迁移任务；已经保存的任务和消息会继续使用。
- 如果微信主动通知暂时不可用，按任务列表底部说明，在微信中给 ClawBot 发一条普通消息即可恢复。

## 已知限制

- 微信主动通知依赖微信仍认可当前回复上下文；长时间没有互动时，仍可能需要你先发一条消息刷新。
- 超过一小时仍未补发的结果会丢弃，不会在之后重新出现。
