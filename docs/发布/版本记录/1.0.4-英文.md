# WeRelay 1.0.4

Release date: 2026-11-15

## What's new

- Updated connection-service components to address newly disclosed security issues and made message journal packaging consistent on Windows.

- Added a message journal to browse the last 30 days of user messages by date, project and keyword. Each source requires explicit consent; revocation immediately hides its messages. Assistant replies and attachment bodies are not read, and no model is called.
- Terminals and projects follow recent message activity while preserving expanded groups.
- A more compact Agent picker uses consistent icons and confirms selection after switching. Switching and running indicators are clearer.
- Includes previously deployed mobile editing improvements: a visible composer above the keyboard, steadier input-method composition and long-text editing, reliable background recovery, and clearer new-task model selection and connection feedback.

## Upgrade

Update both the local program and public Relay, then reopen the mobile page. Existing pairing, history and access passwords remain. The message journal reads no sources until enabled on its source settings page.

## Known limitations

- The journal covers supported sources and the last 30 days of user messages, not complete history. Some sources need local log-reading utilities.
- Mobile keyboard and input-method behavior varies by browser. Real mobile, Agent and ClawBot acceptance remains with the user.
- WeChat notifications require an accepted reply context. After long idle periods a fresh message may be needed.
