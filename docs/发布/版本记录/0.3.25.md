# WeRelay 0.3.25

更新日期：2026-10-30

## 这次更新

- 消息记录页可以按所属项目筛选，并与消息来源、终端、时间和交付状态组合查询；同名但不同目录的项目不会混在一起，暂时无法确认归属的记录会单独显示。
- 常用筛选保留在首行，其他条件收进“更多筛选”；消息状态整理为“处理中”“已发送”“需关注”“已结束”，同时保留具体交付详情。
- 点击消息记录即可在当前页面预览原任务的最近对话，不会切换终端、离开设置页或改变当前任务。AI 回复默认显示末尾三行，可随时展开和收起。
- 消息是否送出与任务是否仍在运行分开展示，避免把“已送达”误当作任务已经结束。

## 升级说明

- 无需重新登录、配对或迁移任务。手机页面仍显示旧界面时，刷新一次即可。
- 项目归属来自电脑已有的任务信息；缺少信息时先显示“未归属项目”，正常刷新任务目录后可补充，不会为分类偷偷启动终端。
- 筛选、统计和导出使用同一范围。项目名与消息摘要仍可能包含个人信息，分享导出文件前请自行审查。

## 已知限制

- 原任务或终端不可用时，预览会明确提示并提供重新读取，不会自动建立替代任务。
- 任务运行状态缺少可靠信息时显示待确认，不根据消息交付状态推算完成。
- 此前观察到的中继短暂断开后恢复现象，本次未宣称修复。
- 真实 Agent 与 ClawBot 的收发、审批和回复回推由你更新后自行体验，本次不自动发送测试消息。
