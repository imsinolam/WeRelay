# WeRelay 0.3.22-preview.20261027.1

体验候选日期：2026-10-27

## 这次更新

- ClawBot 默认每页显示 15 条任务，仍然可以指定显示数量、翻页或按编号给原任务发消息。
- 微信和网页任务列表统一使用“运行中”说明任务状态，微信继续保留绿色标记。
- Pi 开始准备回复时就会显示运行状态，不必等正文出现；刚创建、还没有写入第一条消息的原任务也可以被发现。
- Pi 准备失败或恢复空闲后，运行标记会及时清除，避免已经停止的任务一直显示为运行中。

## 使用说明

- 无需重新登录或配对，已有任务与消息保持不变。
- 已经打开的 Pi 窗口需要等当前任务结束后正常执行 `/reload`，或由你重新打开，才能加载新的状态同步能力。升级不会强制关闭正在运行的 Pi。

## 已知限制

- 这是供实际体验的候选版本，尚未作为 GitHub 正式版本发布。
- Pi 只支持已接入的原任务；不能控制的桌面专有记录不会被当成完整支持，也不会另开一份对话代替。
- 微信主动通知仍依赖有效回复上下文，长时间未互动后可能需要先向 ClawBot 发一条普通消息。
