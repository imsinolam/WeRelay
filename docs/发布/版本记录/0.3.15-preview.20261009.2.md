# WeRelay 0.3.15 体验候选

体验日期：2026-10-09

## 这次更新

- 手机任务台可读取更多电脑终端实际提供的模型和推理选项；不支持的设置会说明原因，不再显示虚假的档位。
- WorkBuddy 即使不是当前选择的终端，也可接收其已有任务的执行审批提醒，不必为查看审批切换桌面任务。
- 电脑解锁时，主动完成和审批提醒会合并发送，减少打扰；锁屏或无法判断电脑状态时，仍及时逐条提醒。用户主动发送指令后的回复不受此限制。

## 修复的问题

- 电脑已收到手机消息、但确认返回较慢时，尽量核对原任务的真实状态，不再因为超时自动重复发送。
- 新版延续 Pi 原任务接入、任务看板设置和完成状态修复。

## 升级说明与限制

- 已打开的 Pi 窗口需要在原窗口执行 `/reload`，才能启用新增模型设置；OpenCode 的设置插件需要原服务正常重启后加载。
- 解锁期间的主动审批提醒可能等待最多十分钟，可随时主动查询任务并处理审批。
- 不同终端版本提供的设置不同；尚未完成真实终端验收的能力，不视为已经全面支持。
- 这是体验候选，不是 GitHub 正式新版本。正式发布前还需核验真实审批、消息发送和微信送达。
