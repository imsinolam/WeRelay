# WeRelay 0.3.1

Release date: 2026-08-23

## What changed

- Mobile web now distinguishes between a request reaching the computer, being handed to the selected agent, and being accepted by that agent. Longer waits show the real delivery stage instead of claiming that processing has already started.
- ClawBot task entry points remain concise. A short link is sent only after the public Relay confirms that it is usable, preventing users from receiving an address that cannot open.

## Fixed

- Fixed mobile web reporting that an agent had started processing while the computer was still handing over the request.
- Fixed ClawBot exposing a long internal link or an unusable link when short-link registration failed or timed out. It now directs the user to the task list instead.
- Fixed some completion and queued-message notifications being forwarded to WeChat before their short links were confirmed.

## Upgrade notes

- Upgrade both the desktop WeRelay installation and the public Relay, then safely restart the existing services.
- Existing WeChat login, mobile-web password, device pairing, and task records do not need to be configured again.

## Known limitations

- When the public Relay is temporarily unreachable, ClawBot cannot create a new task short link. Send “任务” to enter from the task list instead.
- WeChat completion and approval notifications still depend on a valid WeChat context. After a long idle period, sending a fresh message to ClawBot may be required.
