# WeRelay 0.3.4

发布日期：2026-08-24

## 这次更新

- 移动网页的设置现在直接显示在主界面中，切换终端、查看运行状态和调整审批方式更直观。
- DeepSeek Harness 的模型菜单现在会显示所有已接入来源的可用模型；新建空白任务首次发送图片时，也会自动选择可处理图片的模型。
- 移动网页读取消息和发送后的状态更新更快，已经引导到当前任务的后续消息会立即显示，不会短暂消失。
- ClawBot 的任务回复指引和任务链接更清楚，链接保持可点击，并继续进入原来的电脑任务。

## 修复的问题

- 修复 DeepSeek Harness 失败时只显示笼统错误、难以判断是模型、图片能力还是服务返回异常的问题。
- 修复 DeepSeek Harness 事件连接中断后每秒重复发送告警的问题；同一次中断只提醒一次，恢复后会明确通知。
- 修复部分终端明明正在处理任务，移动网页仍显示为空闲的问题。
- 修复手机端长按任务、运行状态和终端菜单在部分屏幕尺寸下显示不稳定的问题。

## 升级说明

- 请同时升级电脑端 WeRelay 和公网 Relay，并安全重启现有服务。
- 已有微信登录、网页访问密码、设备配对、任务记录和短链接无需重新配置。
- DeepSeek Harness 用户请保持电脑上的 Harness Host 正常运行；WeRelay 会优先连接已经运行的桌面 Harness。

## 已知限制

- DeepSeek Harness 可选择的模型和图片能力取决于本机 Harness 已配置并实际可用的模型来源。
- 电脑端 Agent 或公网 Relay 暂时离线时，移动网页会显示当前等待阶段；恢复连接前不能执行新的远程操作。
