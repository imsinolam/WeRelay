# WeRelay 0.3.15

发布日期：2026-10-09

## 这次更新

- 手机任务台增加“整理会话”入口，可以按项目和处理状态查看已有任务。对不清楚的标题提供建议，只有手动确认后才改名，不自动修改任务内容。
- 手机任务台可以读取更多终端实际提供的模型与推理选项；终端不支持的设置会说明原因，不再把猜测的选项当作真实能力。
- 延续 Pi 原任务接入：手机和微信的文字消息进入电脑上的同一个可见任务，不暗中另开对话。

## 修复的问题

- 从手机继续尚未在桌面加载的 Codex 任务时，会留出确认时间。只有明确确认原任务未加载时才打开它，减少因等待过短而提示未发送的情况。
- 改善手机消息的确认、去重与失败恢复；不能确认是否送达时不会轻率地当作失败重新发送。
- 改善任务完成状态的同步，减少已经回复后网页仍停留在等待状态的问题。

- 更新通信组件及相关依赖，修复发布检查发现的安全漏洞。

## 升级说明

- 已打开的 Pi 窗口需要在原窗口执行 `/reload`，才能加载新增设置；不需要复制任务文件或重新创建任务。
- 整理会话需要先登录任务台。不支持改名的终端不会显示保存入口。
- 本版本通过 GitHub 提供源码和安装包，不发布到 npm 公共仓库。

## 已知限制

- 微信可能间歇性拒绝发送通知。本次已验证原任务收发及完成回复回推，但不代表所有推送持续稳定；需要时可向 ClawBot 发新消息刷新回复上下文，不能承诺固定有效时长。
- WorkBuddy 增加跨任务审批观察与解锁时合并提醒的支持，但真实审批和锁屏场景尚未完成实机验收，暂不承诺完整可用。
- 公网访问可用；自动切换到局域网的完整交接仍待验收，遇到问题请继续使用公网地址。
- Pi 的图片、审批回传及从微信执行 Pi 自身的斜杠命令仍不支持。
