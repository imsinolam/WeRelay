# WeRelay 0.3.1

发布日期：2026-08-23

## 这次更新

- 移动网页发送消息时会分别显示“正在到达电脑”“正在转交终端”和“终端已经接收”，等待较久时也能看清消息停在哪一步，不会过早显示为已经开始处理。
- ClawBot 中的任务入口继续保持简短链接；只有公网 Relay 确认链接已经可以使用后才会发送，避免用户收到打不开的地址。

## 修复的问题

- 修复网络较慢时，网页可能把“请求已经到达电脑”误显示成“终端已经开始处理”的问题。
- 修复任务短链接登记失败或超时时，ClawBot 可能发出过长的内部链接或失效链接的问题。现在会改为提示从“任务”列表进入，不再发送不可靠地址。
- 修复部分完成通知和待发送通知没有在发给微信前确认短链接可用的问题。

## 升级说明

- 请同时升级电脑端 WeRelay 和公网 Relay，并安全重启现有服务。
- 已有微信登录、网页访问密码、设备配对和任务记录无需重新配置。

## 已知限制

- 公网 Relay 暂时不可达时，ClawBot 无法生成新的任务短链接；此时可以发送“任务”，从任务列表进入。
- 微信完成通知和审批通知仍受微信上下文有效期影响，长时间没有新消息时，可能需要先向 ClawBot 发送一条新消息恢复上下文。
