# WeRelay 0.3.31

Updated: 2026-11-05

## Changes

- The mobile web now lets you choose a model and reasoning effort for a task's next message. The selected settings remain visible until the desktop confirms them instead of jumping back to the old choice.
- Mobile web now updates the current task when new messages, task changes, or run-state changes arrive. It also prepares recently used tasks in the background so switching between tasks takes less time.
- Agent ordering in the mobile sidebar better follows recent use, and the selected Agent icon remains clear and balanced.
- The end of a parent task conversation can expand a read-only "child tasks" section. Viewing a child task does not switch the current task, clear drafts, or send a message to the child.

## Fixes

- After choosing a model setting on mobile, the page could show the old model too early and make the choice appear not to have taken effect.
- Some desktop application quit and reconnect messages were misleading. They now describe the actual state and next step.
- Some internal Codex, DeepSeek Harness, and OpenCode child tasks could appear in normal task lists or be opened as independent tasks. They now remain linked to the parent task, while approvals continue to work normally.

## Upgrade

Refresh the mobile web page to load the new interface. The local background program needs the update and a reconnect; WeChat pairing and installed Agents do not need to be set up again.

## Limitations

- Child tasks appear only when the desktop provides a reliable parent-child relationship. If the original terminal is disconnected or the relationship cannot be read, the page shows an error and lets you retry.
- Model and reasoning-effort selection depends on support from the selected terminal. Unsupported terminals show a clear message instead of silently sending with older settings.
- This release does not change the existing requirement for a valid WeChat reply context for proactive delivery, nor other existing rules for live Agents and WeChat. Users verify those flows after updating.
