# WeRelay 0.3.15 体验候选

体验日期：2026-10-09

## 这次更新

- 增加“整理会话”入口，按项目和处理状态查看已有任务。对不清楚的标题给出建议，只有手动确认后才改名，不自动改动任务内容。
- 手机任务台能读取更多终端真实提供的模型和推理选项，不支持的设置会说明原因。
- WorkBuddy 的其他已有任务也能提供审批提醒；电脑解锁时，主动提醒会合并发送，减少打扰。

## 修复的问题

- 从手机继续尚未在桌面加载的 Codex 原任务时，给桌面留出确认时间；只有明确确认任务未加载时才打开原任务，不再因为等待过短反复提示未发送。
- 延续手机消息确认与去重、Pi 原任务接入及任务完成状态的修复。

## 使用与限制

- 整理会话需要先在任务台登录。标题建议仅供参考，不支持改名的终端不会提供保存入口。
- 已打开的 Pi 窗口需执行 `/reload` 才能加载新增设置；其他终端的设置依赖各自实际能力。
- 这是体验候选，不是 GitHub 正式版本。消息发送、微信回推和真实审批仍以实机验收结果为准。
