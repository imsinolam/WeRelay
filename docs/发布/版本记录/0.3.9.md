# WeRelay 0.3.9

发布日期：2026-09-08

## 这次更新

- 手机网页的模型菜单更宽，终端按近期使用情况排列；打开侧边栏时自动定位当前任务。
- 微信任务列表的操作说明按进入、发送、搜索和翻页分组，各终端使用一致的提示。
- 可以预览明确选择的工作区外文件，页面自动引用的资源仍受目录边界限制。
- 调整输入框彩色光带在明亮与深色主题下的显示，并保留减少动态效果选项。

## 修复的问题

- 已经送达或实际执行的消息会核对执行记录，减少缓存恢复后仍显示失败、重复气泡或重复提交的情况；分页查看历史时也能保留送达确认。
- 修复微信补发旧完成通知时，刚收到的消息可能被转向另一个任务的问题。
- 修复从手机继续 Codex 原任务时，文字输入格式可能导致电脑端页面解析异常的问题，保留图片和已有输入内容。

## 升级说明

- 无需修改现有连接配置；已打开的手机网页会检测新版本并更新。
- 如果 Codex 页面仍保留升级前的异常状态，请在其他任务可安全中断后完整退出并重新打开。
- 微信长期未交互后，完成通知可能需要先发送一条新消息才能恢复。

## 已知限制

- 持续投递仍要求电脑端保持运行；执行记录不足时会保留失败提示，不会擅自删除消息。
- 桌面页面的显示效果仍需用户实际观察，后台回复成功不代表所有桌面显示问题均已解决。
