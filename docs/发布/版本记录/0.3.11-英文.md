# WeRelay 0.3.11

Release date: 2026-09-11

## Improvements

- Switching terminals can now specify how many tasks to list, for example `/codex 20` lists 20 tasks right after switching, so you no longer need a separate page request.
- Links inside the WeChat task list no longer gain extra spaces, and a blank line now separates the list from the trailing instructions, making them easier to read and tap on a phone.

## Fixes

- **Fixed an empty message when switching to DeepSeek Harness failed.** Previously, if the desktop host was not ready, WeChat could receive an error with no content. It now states the real reason and what you can do to retry.
- De-linked URLs and file names in the WeChat task list no longer leave stray spaces behind.

## Upgrade notes and limitations

- No extra steps are required; restart WeRelay after upgrading.
- Upgrading from 0.3.10 or earlier keeps existing configuration, login state, and task history; no re-login or reconfiguration is needed.
- If WeChat completion delivery asks for a fresh message, send ClawBot one normal message to refresh the session.
- The number of tasks you can request is capped; anything beyond the cap still needs paging.
- After the computer restarts, the first service recovery can take one to several minutes, during which the web page and ClawBot are temporarily unavailable. Please retry once it finishes.
