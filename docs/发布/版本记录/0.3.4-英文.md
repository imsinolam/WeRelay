# WeRelay 0.3.4

Release date: 2026-08-24

## What changed

- Mobile settings now open directly in the main workspace, making terminal switching, live status, and approval preferences easier to understand.
- The DeepSeek Harness model menu now shows available models from every configured provider. A new empty task also selects an image-capable model when its first message contains an image.
- Mobile message reads and delivery-state updates are faster, and a follow-up steered into the current task remains visible immediately instead of briefly disappearing.
- ClawBot task-reply guidance and task links are clearer, remain clickable, and continue in the original desktop task.

## Fixed problems

- Fixed vague DeepSeek Harness failures that did not distinguish model errors, unsupported images, or upstream service responses.
- Fixed repeated disconnect warnings being sent every second during one DeepSeek Harness event-stream outage. One outage now produces one warning and an explicit recovery notice.
- Fixed connected non-Codex tasks sometimes appearing idle while they were actively running.
- Fixed unstable long-press behavior, runtime status, and terminal-menu layout on some mobile screen sizes.

## Upgrade notes

- Upgrade both the desktop WeRelay installation and the public Relay, then restart the existing services safely.
- Existing WeChat login, web password, device pairing, task history, and short links do not need to be configured again.
- DeepSeek Harness users should keep the local Harness Host running. WeRelay prefers the already running desktop Harness owner.

## Known limitations

- Available DeepSeek Harness models and image support depend on the providers that are configured and actually available in the local Harness.
- When the desktop Agent or public Relay is offline, the mobile page shows the current waiting stage; new remote actions cannot run until the connection recovers.
