# WeRelay 0.3.2

Release date: 2026-08-23

## What changed

- Opening a WorkBuddy task from mobile web or ClawBot now connects directly to the same WorkBuddy desktop task, so the phone and computer continue one shared conversation.
- Mobile users can continue sending messages, answer permission requests, and stop work while results remain in the original WorkBuddy task instead of a separate hidden session.
- When an existing WorkBuddy task is selected, WeRelay now opens and attaches to that exact task instead of connecting to a different one.

## Fixed

- Fixed mobile messages being processed without appearing in the WorkBuddy desktop window.
- Fixed WeRelay restarting an already-open WorkBuddy application or silently switching to another session when desktop connectivity was not ready. It now preserves the selected task and reports the connection state.
- Fixed replayed output from an existing task being mistaken for the new reply after reconnection.

## Upgrade notes

- Upgrade both the desktop WeRelay installation and the public Relay, then safely restart the existing services.
- Existing WeChat login, mobile-web password, device pairing, and task records do not need to be configured again.

## Known limitations

- WorkBuddy desktop handoff currently supports macOS and requires an installed, signed-in, and compatible WorkBuddy version running on the computer.
- If WorkBuddy is upgrading, starting, or temporarily unavailable, WeRelay preserves the original task and asks the user to retry instead of switching to another session.
