# WeRelay 1.0.5

发布日期：2026-11-15

## 这次更新

- 消息日历自动更新时更省流量。没有新消息时只确认“已是最新”，不再反复传回整页消息。
- 保存消息来源遇到网络超时后，会核对电脑上实际保存的结果。确认成功就继续进入日历，不把超时误报为失败。
- 再次保存相同的消息来源不会清空已有日历内容或重新开始扫描。

## 升级说明

本机后台程序与公网 Relay 一并更新后，重新打开手机网页即可使用。原有消息来源授权、任务历史和访问密码保留，不需要重新设置。

## 已知限制

- 消息日历只展示支持来源最近 30 天的用户消息，不代表完整历史。
- 电脑离线时仍无法读取新的日历内容；页面会保留已有数据并提示稍后重试。
- 真实手机、Agent 与 ClawBot 使用体验由用户确认。
