# 0.3.13 experience update

This is an experience candidate, not a formal GitHub release.

- Stop pending messages from lingering forever: a message still awaiting native confirmation after one hour leaves the pending list, returns to the transcript with its content preserved, and stops blocking the interface.
- Make the delete and edit actions work on such messages: delete cancels the local pending send without resending, and edit pulls the text back into the composer.
- Fix WeChat task short links that ended in `-` or `_` and were therefore not recognised as links, so they now open normally. New aliases use letters and digits only; previously issued links keep working.
- Show the WorkBuddy task list even before the daemon has established a connection for it, without exposing rename, create or send until connected.
- Offer a new-task entry in the recent group for adapters without projects, such as Grok.

No new pairing is required. Original conversations are preserved. WeChat context validity, sleep and network failures still need real-world acceptance; this candidate does not promise to eliminate every delivery or connection failure.
