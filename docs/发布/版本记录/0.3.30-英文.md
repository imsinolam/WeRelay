# WeRelay 0.3.30

Updated: 2026-11-02

## Changes

- The mobile task title, project name, sync state, and new-task action now stay on one row, so long titles no longer push the header onto a second line.
- Project information appears only when there is a real project name; internal placeholders such as "workspace" and "untitled project" are no longer shown as projects.

## Fixes

- After creating a task on mobile and sending the first message, the page could remain on the temporary task or retain both the temporary and real task. It now moves to the real task while preserving the draft, unsent messages, and conversation, without creating a duplicate.

## Upgrade

Refresh the web page; no WeChat pairing or Agent reinstallation changes are needed.

## Limitations

- This release does not change the existing rules for live Agents, WeChat messaging, or approvals. Users verify those flows after updating.
