# WeRelay 0.3.9

Release date: 2026-09-08

## Improvements

- Wider mobile model menus, terminals ordered by recent use, and automatic scrolling to the current sidebar task.
- Consistent, grouped WeChat instructions for selecting tasks, sending messages, searching, and pagination.
- Preview explicitly selected files outside the workspace while keeping automatically referenced resources within directory boundaries.
- Refined composer lighting for light and dark themes, respecting reduced motion.

## Fixes

- Reconcile delivered or executed messages with retained acknowledgements to reduce stale failure indicators, duplicate bubbles, and resubmissions after cache restoration or history pagination.
- Keep incoming WeChat replies targeted correctly while older completion notifications are replayed.
- Normalize mobile text input for the original Codex desktop task to avoid a desktop parsing error, preserving images and existing input metadata.

## Upgrade notes and limitations

- Existing connection settings remain valid; open mobile pages detect the new version.
- If an old desktop error state persists, fully quit and reopen Codex only when other tasks can safely be interrupted.
- After a long WeChat idle period, send a fresh message to restore completion notifications.
- Background delivery requires the computer to remain running. Insufficient execution evidence leaves failed messages intact.
- Desktop visuals still require user observation; successful background replies do not prove every desktop display issue is resolved.
