# WeRelay 0.3.22-preview.20261028.1

Preview date: 2026-10-28

## Changes

- Open the same task on the web to continue an unsent plain-text draft from the native app.
- Existing web edits are preserved. Changes to the native draft require review rather than silently sending stale content.
- Includes the previous preview: prompt Pi running-status updates and 15 tasks per ClawBot page by default.

## Usage

- No new login or pairing is required; existing tasks remain unchanged.
- Existing Pi windows need an idle `/reload` or a normal reopen to load the updated extension. Running windows are not forcibly closed.

## Limitations

- Draft import is limited to safely readable Codex plain text and Pi owners exposing editor APIs. Other agents, rich text and attachments are not imported.
- Simultaneous sends from two devices have not been accepted as a supported race-free workflow. Check the original task before sending.
- The previous preview could not obtain a live Desktop receiver for the dedicated Codex acceptance task. New-turn delivery and WeChat final-reply delivery still require verification; history reads do not prove delivery.
- This is an experience preview, not a formal GitHub release.
