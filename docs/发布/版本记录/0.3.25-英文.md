# WeRelay 0.3.25

Updated: 2026-10-30

## Changes

- Filter message records by project alongside source, agent, time and delivery status. Different directories with the same name remain separate; unknown attribution is shown explicitly.
- Common filters stay visible while advanced conditions move into More Filters. Delivery is grouped into processing, sent, needs attention and closed, with detailed statuses still available.
- Open a record to preview recent conversation in place without switching agent, leaving settings or changing the selected task. Assistant replies show their last three lines by default and can be expanded or collapsed.
- Delivery state and live task state are shown separately, so confirmed delivery does not imply task completion.

## Updating

- No login, pairing or task migration is required. Refresh the mobile page if it still displays the previous interface.
- Project attribution uses existing cached task metadata. Unknown records can be enriched after a normal task catalog refresh without starting an agent for classification.
- Filters, statistics and exports share the same scope. Project names and summaries may contain personal information; review exports before sharing.

## Limitations

- Unavailable tasks or agents show a preview error with a retry action rather than creating a replacement task.
- Missing live task signals are marked unknown; completion is never inferred from delivery.
- Previously observed relay disconnects and recovery are not declared fixed by this update.
- Live agent messaging, approvals and ClawBot replies are left for the user to try after installation; no acceptance messages are sent automatically.
