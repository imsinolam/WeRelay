# WeRelay 0.3.22-preview.20261027.1

Preview date: 2026-10-27

## Changes

- ClawBot now lists 15 tasks per page by default. Custom page sizes, pagination, stable task numbers and sending to the original task remain available.
- WeChat and mobile task lists use consistent running-state labels. WeChat retains its green indicator.
- Pi reports a running task during reply preparation, before output appears. New original sessions can also be discovered before their first message is saved.
- Failed preparation and a return to idle clear Pi's running state instead of leaving a stale indicator.

## Upgrade

- No sign-in or pairing changes are needed. Existing tasks and messages are preserved.
- Existing Pi windows need a normal `/reload` after the current task finishes, or a user-initiated reopen, to load the updated extension. Running Pi tasks are not forcibly restarted.

## Limitations

- This is an experience candidate, not a formal GitHub release.
- Pi support remains limited to connected original owners and native session records. Unsupported desktop-private records are not controlled through replacement conversations.
- Proactive WeChat notifications still require a valid reply context. Send ClawBot an ordinary message after a long idle period if needed.
