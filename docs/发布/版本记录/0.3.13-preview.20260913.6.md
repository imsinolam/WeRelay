# 0.3.13 体验更新（2026 年 9 月 13 日，第六次）

本次是集中体验更新，尚未发布为 GitHub 正式版本。

## 更稳定地连接电脑

- 读取多个终端的任务列表时，把耗时工作移到后台，减少网页卡顿、微信无响应和误报电脑离线。
- 后台读取长时间无响应时会结束本次等待并允许重新读取，避免一直卡住。
- 公网连接单独保持在线，单个任务读取慢不再拖住设备保活；发送结果不明确时仍保留防重复保护。
- 改善 DeepSeek Harness 实时事件与历史同步，短暂断线不再连续刷屏，读取历史失败不会直接拖垮连接。

## 更清楚的 ClawBot 提示

- 任务列表说明改为“给任务3发消息”，按操作分组显示。
- 去掉任务列表重复标题，以及正常切换终端后的重复成功通知。
- 连接异常提示说明正在自动恢复；保留真正需要处理的错误。

## 使用提示与限制

无需重新配对；任务仍继续原有上下文，不会为了恢复而另建任务。微信凭据失效时仍可能需要发送新消息刷新上下文。本次未取消相关保护，也不保证所有网络或桌面端异常都能自动恢复。

开发完成后会先验证、提交并登记，由用户明确要求时集中部署，不再每个小改动单独重启服务。
