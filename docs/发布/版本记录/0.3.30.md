# WeRelay 0.3.30

发布日期：2026-11-02

## 这次更新

- 手机网页顶部的任务名称、项目名称、同步状态和新建入口保持在同一行，较长的标题不会再把页头挤成两行。
- 顶部只在有真实项目名称时显示项目信息，不再把“工作区”“未命名项目”等内部占位文字当成项目名称。

## 修复的问题

- 从手机新建任务并发送第一条消息后，页面曾可能停留在临时任务上，或者同时留下临时任务和真实任务。现在会切到真实任务，草稿、尚未发送的消息和对话内容继续保留，也不会重复创建。

## 升级说明

网页刷新即可载入新界面，无需重新配对微信，也无需重新安装正在使用的 Agent。

## 已知限制

- 本次不改变真实 Agent、微信收发和审批的原有规则；这些链路由用户在更新后自行体验。
