# WeRelay 0.3.22-preview.20261030.1

体验候选日期：2026-10-30

本候选包含上一体验版的全部更新，并继续改善手机网页的消息显示与操作。

## 这次更新

- 手机发送图片后，更准确地识别电脑端已经收到的消息，减少同一条内容重复显示或一直停留在待确认状态。
- 正在排队的消息会保留原来的身份；较晚返回的发送结果不会把已经送达或取消的消息重新显示出来。主动重复发送的不同消息仍分别保留。
- 放大任务标题菜单的点击区域，并增加操作图标，手机上更容易点选。
- 统一聊天正文、图片、排队卡片和输入框的界面实现，保留草稿、模型选择及原任务的使用方式，为后续界面改进减少不一致。

## 使用说明

- 不需要重新登录或配对。打开网页后如仍看到旧界面，可刷新页面。
- 已有任务、草稿和附件继续保留，不会为更新另建对话。
- 部署后由你亲自验收 Agent 和 ClawBot 的收发、审批及回复回推；部署 Agent 只检查服务、网页和连接的基础状态，不自动发送测试消息。

## 已知限制

- 微信主动回推仍依赖微信认可的回复上下文，长时间未互动后可能需要先发送一条消息。
- 这是体验候选，尚未作为 GitHub 正式版本发布；真实手机与各 Agent 的使用体验仍待你确认。
