# WeRelay 0.3.11

发布日期：2026-09-11

## 这次更新

- 切换终端时可以直接指定任务列表的条数，例如发送 `/codex 20` 会在切换后一次列出 20 条任务，不必再单独翻页。
- 微信任务列表里的链接不会再被拆出多余空格，列表末尾的操作说明前面也会留出空行，手机上阅读和点击都更清楚。

## 修复的问题

- **修复了切换 DeepSeek Harness 失败时提示为空的问题。** 之前切换遇到桌面端未就绪等异常，微信里可能只收到一句没有内容的错误；现在会说明真实原因，并提示可以怎么重试。
- 微信任务列表里的网址、文件名等去链接化后不再残留多余空格。

## 升级说明

- 升级后无需额外操作，重启 WeRelay 即可。
- 从 0.3.10 或更早版本升级会自动沿用现有配置、登录状态和任务记录，不需要重新登录或重新配置。
- 如果微信完成通知提示需要新消息，请先在微信里给 ClawBot 发送一条普通消息以刷新会话。

## 已知限制

- 指定任务列表条数时会限制在一个上限内，超出部分仍需要翻页查看。
- 电脑重启后首次恢复服务可能需要一到几分钟，期间网页和 ClawBot 暂时不可用；恢复完成前请稍候再试。
