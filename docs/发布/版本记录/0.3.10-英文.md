# WeRelay 0.3.10

Release date: 2026-09-11

## Improvements

- The public task console opens faster on mobile: the relay server prepares the terminal list, task board, and the latest task messages in advance, so the page shows existing content instead of a blank wait.
- Each AI reply now shows its completion time underneath; across days it reads “Yesterday 18:30” or “Aug 30 18:30”, making it easy to tell a just-finished reply from an older one.
- The DeepSeek Harness model menu uses two levels when more than one model source is available: pick a source first, then the model. With a single source the models are still listed directly, so the previous habit is unchanged.
- When a WeChat send result cannot be confirmed, WeRelay pauses automatic resends and asks you to verify, instead of risking a duplicate notification.

## Fixes

- **Fixed an issue where the task console could make the computer appear offline.** Previously, every few seconds the web page read the task board by synchronously walking each terminal's stored session directories. With enough sessions this occupied the main thread for a long time, so the phone showed “computer offline”, the web page would not open, and WeChat replies stopped arriving — even though the computer looked fine. The same read now reuses its result for a short window and merges concurrent requests into one, so it no longer repeatedly blocks.
- **Fixed long unavailability after a restart.** Each startup used to re-apply permissions to every file in the runtime directory and repeatedly compare it against old product directories; once files accumulated into the tens of thousands, startup took several minutes before service returned. Permissions are now left alone when already correct, and the old-directory comparison runs only once, making startup noticeably faster.
- A just-sent message on the web page no longer appears twice once the real record arrives, and it is no longer rendered in two places while sending.
- The pending animation at the end of a message now stops promptly when the task has finished, and continues while the task is still working.

## Upgrade notes and limitations

- No extra steps are required; restart WeRelay after upgrading.
- Upgrading from 0.3.9 or earlier keeps existing configuration, login state, and task history; no re-login or reconfiguration is needed.
- If WeChat completion delivery asks for a fresh message, send ClawBot one normal message to refresh the session.
- A few WorkBuddy desktop connection tests are skipped on Windows (that desktop app is macOS-only); this does not affect real use on macOS or Linux.
- If the runtime directory again accumulates a large number of files — for example by storing release backups inside it — startup will still be slower than usual; keep backups outside the runtime directory.
