# WeRelay 1.0.4

发布日期：2026-11-15

## 这次更新

- 更新连接服务所用的基础组件，修复新披露的安全问题，并修正 Windows 上消息日历安装包的校验兼容性。

- 新增消息日历：在任务台中按日期、项目和关键词查看最近 30 天的用户消息。首次使用需自行选择允许读取的来源，取消后立即停止展示；不会读取助手回复、附件正文或调用模型。
- 终端和项目按最近消息活动排序，更容易找到刚刚使用的任务；重新排序时会保留分组的展开状态。
- 终端选择器更紧凑，统一图标与选中提示。切换完成后再确认选中，正在切换和正在处理的提示更清楚。
- 同时公开此前已部署的手机输入优化：键盘弹出时输入框保持可见，中文组词、长文本编辑和后台恢复更稳定，新建任务的模型选择与连接提示更准确。

## 升级说明

本机后台程序与公网 Relay 一并更新后，重新打开手机网页即可使用。原有微信配对、任务历史和访问密码保留。消息日历默认不读取任何来源，需要在页面中授权。

## 已知限制

- 消息日历仅展示支持来源最近 30 天的用户消息，不代表完整历史；部分来源需要电脑上相应的日志读取工具。
- 不同手机浏览器的键盘与输入法仍有差异，真实手机及 Agent、ClawBot 收发体验由用户确认。
- 微信通知依赖有效的回复上下文，长时间未互动后可能需要发送新消息恢复。
