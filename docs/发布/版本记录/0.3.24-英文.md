# WeRelay 0.3.24

Updated: 2026-10-30

## Changes

- The mobile taskboard now keeps an actionable connection notice above the composer when a desktop agent is unavailable. Retrying preserves the selected task, draft and pending messages.
- A new Message Records settings page provides filters for ClawBot or web source, agent, time and delivery status, plus delivery timelines and filtered export.
- Statistics cover retained and filtered records only. Retries do not count as new messages, and submission does not imply task completion.
- Recording can be paused, text retention and limits adjusted, or diagnostic records cleared without changing original conversations or the delivery queue.
- Messages already submitted or queued are no longer incorrectly marked failed when a later notification fails.

## Updating

- No login, pairing or task migration is required. Refresh the mobile page if it still shows the previous interface.
- By default, short summaries with best-effort secret redaction are stored in the computer's private workspace, with 30-day, 5000-record and size limits. These settings can be changed or disabled.
- Summaries and exports may still contain paths or personal information from message text. Review before sharing. Disabling these diagnostic records does not remove the agent's conversations or existing runtime logs.

## Limitations

- Earlier ClawBot messages are not imported. Web history is limited to retained outbox snapshots, not lifetime totals.
- Without a real receipt from the original agent, records remain submitted or queued rather than claiming confirmed delivery.
- Previously observed relay disconnects and recovery have not been declared fixed by this update.
- Live agent messaging, approvals and ClawBot replies are left for the user to try after installation; no acceptance messages are sent automatically.
