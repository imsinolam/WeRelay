# WeRelay 0.3.22-preview.20261030.1

Experience candidate date: 2026-10-30

This candidate includes all updates from the previous candidate and further improves the mobile web experience.

## Updates

- More accurately recognize image messages already received on the computer, reducing duplicate messages and entries stuck awaiting confirmation.
- Queued messages keep their original identities. Late send results no longer bring back delivered or cancelled entries. Separate messages intentionally sent again remain distinct.
- Larger task-title menu hit areas and added action icons make mobile operations easier.
- Chat text, images, queue cards and the composer now share a common implementation, retaining drafts, model selection and original-task behavior while reducing inconsistencies in future UI changes.

## Usage

- No new login or pairing is required. Refresh the web page if an older interface remains visible.
- Existing tasks, drafts and attachments are preserved; the update does not create replacement conversations.
- You will check real Agent and ClawBot messaging, approvals and final-reply delivery after deployment. Deployment checks cover service, web and connection basics without sending test messages.

## Known limitations

- Proactive WeChat notifications still require a reply context accepted by WeChat. After a long idle period, sending a fresh message may be necessary.
- This is an experience candidate, not a formal GitHub release. Real mobile and Agent usage remains subject to your confirmation.
