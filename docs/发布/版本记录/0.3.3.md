# WeRelay 0.3.3

发布日期：2026-08-23

## 这次更新

- 现在从移动网页或 ClawBot 向已经打开的 Codex Desktop 任务发送消息时，会继续进入电脑上的原任务，不会因为桌面应用升级而停在“未确认收到”的状态。
- 手机发送成功后会以电脑端实际接受的同一轮任务为准，避免重复发送，也不会静默新建一条替代任务。
- Codex 完成回答后，WeRelay 会等待完整回复写入任务记录，再可靠地把最终结果回推到微信。

## 修复的问题

- 修复 Codex Desktop 升级后，网页和 ClawBot 的消息可能没有进入原任务，却一直等待到超时的问题。
- 修复任务刚完成时回复记录尚未完全写入，导致微信漏收最终回答的问题。
- 修复一次完成通知暂时无法确认时，后续重试状态可能被过早清除的问题。

## 升级说明

- 请同时升级电脑端 WeRelay 和公网 Relay，并安全重启现有服务。
- 已有微信登录、网页访问密码、设备配对、短链接和任务记录无需重新配置。
- 如果升级前有一条消息显示“暂未确认收到”，请先查看电脑上的原任务状态，确认没有执行后再决定是否重发。

## 已知限制

- Codex Desktop 必须保持登录，并且原任务仍可由桌面应用读取；如果桌面应用正在升级、退出或暂时无法连接，WeRelay 会保留原任务并提示稍后重试，不会自动创建替代任务。
