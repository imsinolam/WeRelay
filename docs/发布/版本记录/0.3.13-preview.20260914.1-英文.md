# 0.3.13 experience update

This is an experience candidate, not a formal GitHub release.

- Send task lists before separate usage instructions while preserving task identities, numbering and chunk order.
- Rank Grok tasks by actual activity rather than refreshed summary metadata.
- Keep mobile outgoing messages visible through delivery and native transcript handoff.
- Show incoming Codex task messages with provenance and received timestamps.
- Preselect supported models and reasoning for new tasks, retaining messages if settings cannot be confirmed.
- Keep DeepSeek Harness heartbeats independent of daemon work and reset reconnect backoff after a stable connection.

No new pairing is required. Original conversations are preserved. WeChat context validity, sleep and network failures still need real-world acceptance; this candidate does not promise to eliminate every delivery or connection failure.
