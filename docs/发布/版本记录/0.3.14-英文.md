# WeRelay 0.3.14

Release date: 2026-09-24

## What's new

- Mobile web and WeChat can list existing Pi Agent tasks and send text to the same visible Pi terminal. Replies stay in the original task instead of silently starting another conversation.
- An already open Pi window can be connected by enabling the WeRelay extension and entering `/reload` in that same window.

## Fixes

- Mobile web no longer keeps showing “syncing run status” after Pi has finished replying.
- Codex sends and latest-reply reads from mobile web are more reliable. A temporary terminal check failure no longer makes the task list appear empty.

## Upgrade

- Pi windows opened by WeRelay connect automatically. For a Pi window you opened independently, run `werelay-pi-enable` on the computer, then enter `/reload` in that **same window**.
- No Pi task files need to be copied or migrated. Reopening a closed window must not be mistaken for connecting to the formerly running window.

## Known limitations

- Pi currently supports text tasks and stopping a run. Images, approval replies, and invoking Pi's own slash commands from WeChat are not yet available.
- On Windows, WeRelay cannot safely attach to an independently opened Pi window or automatically resume a Pi task that might still be owned by another process.
- Recovery after sleep, network interruption, or a long WeChat idle period may take a short while. If the WeChat send context has expired, send ClawBot a fresh message first.
