# WeRelay 1.0.6

Release date: 2026-11-17

## Changes

- Restore compatibility with newer Codex Desktop when receiving mobile messages, preserving the original task and synchronized delivery status.
- Improve mobile message input and editing, retain image previews after sending, and preserve attachment display during refresh.
- Make the message journal easier to read on phones, with clearer filters, date navigation, source selection and empty states.
- Reduce repeated journal downloads when unchanged. Verify saved source consent after a timeout and keep existing content when saving the same sources again.
- Add a maintenance tool for reviewing recent message delivery failures without including conversation text, raw errors or local paths in its report.

## Upgrade

Update the local program and public Relay together, then reopen the mobile page. Access passwords, source permissions and original task history are preserved.

## Known limitations

- New messages cannot be read while the computer is offline. The journal shows user messages from authorized sources within the last 30 days.
- WeChat notifications depend on the reply context accepted by WeChat. If sending is temporarily protected, send ClawBot a new message and observe recovery.
- Real mobile, Agent and ClawBot experience remains subject to user acceptance.
