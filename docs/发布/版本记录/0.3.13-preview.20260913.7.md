# 0.3.13 体验更新（第七个候选）

这是集中体验更新，尚未发布为 GitHub 正式版本；保留上一候选的任务列表、DeepSeek Harness 连接改进和 ClawBot 提示调整。

## 长任务阅读更顺畅

- 修复读取含有超长工具记录的聊天历史时，电脑端短暂卡住的问题，减少它对消息响应和连接保活的影响。
- 继续保留原任务和翻页位置，不会为了读取历史另建任务或丢掉较早消息。

## 交付规则更清楚

- 开发任务先验证、提交并登记；仅在用户要求时集中部署，避免多个任务反复重启服务。

## 使用说明

无需重新配对。此版本仍需实际连接验收和持续体验；微信上下文失效或桌面端拒绝请求等问题，不等于历史读取修复已解决。本候选不宣称所有发送和连接问题都已消除。
