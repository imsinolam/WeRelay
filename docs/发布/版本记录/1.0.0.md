# WeRelay 1.0.0

发布日期：2026-11-05

## 这次更新

- WeRelay 进入 1.0 正式版本线。微信、手机任务台与电脑继续连接同一条真实任务，后续更新沿用统一版本号。
- 手机任务台可以为下一条消息选择模型和推理强度，所选设置会保留到电脑端确认。
- 当前任务出现新消息、运行状态或审批变化时，手机页面会自动更新；最近常看的任务会提前准备，减少切换时的等待。
- 主任务对话末尾可以展开相关子任务，以只读方式查看内容，保留当前任务和未发送草稿。
- 页头、终端图标栏和新建任务衔接更稳定，使用短链进入任务或看板更顺畅。

## 修复的问题

- 切换模型后界面可能过早显示旧选项；现在会等待电脑确认，读取设置也不会拖住整页刷新。
- 新建任务或重新连接终端时，可能出现标题、状态与实际任务不一致；现在会继续跟踪真实任务并说明连接状态。
- 内部子任务可能混进普通任务列表；现在保留在主任务关系内，审批仍按实际任务处理。

## 升级说明

本机后台程序需要更新并重新连接，手机网页刷新后载入新界面。已有微信配对、任务历史和访问密码继续保留，无需重装 Agent。版本号进入 1.x 不改变现有数据格式或使用方式。

## 已知限制

- 各 Agent 的桌面同步、模型切换和审批能力不同，以项目首页的能力说明为准；电脑仍需开机、联网并运行 WeRelay。
- 子任务需要电脑端提供可靠的关系记录；读取失败时可重试。
- 微信通知仍需要微信认可的回复上下文；长时间未互动后可能需要给 ClawBot 发一条消息恢复。
- 真实 Agent 与 ClawBot 的收发和审批体验由用户在升级后自行确认。
