# WeRelay 1.0.7

Release date: 2026-11-18

## Changes

- Add a read-only Daily Reviews section in Settings. Reports are ordered by time, keep only the latest snapshot for each day, and expand the most recent report by default.
- Daily reviews show a safe summary, status and next steps without conversation text, raw errors or local paths. The same history is available on mobile.
- Show a green breathing outline around the selected agent icon while switching agents, making the active target easier to notice. The animation stops when switching completes.
- Respect the system reduce-motion setting by keeping the switching indicator static.

## Upgrade

Update the local program and public Relay together, then reopen the mobile page. Access passwords, review history, source permissions and original task history are preserved.

## Known limitations

- Daily reviews are read-only summaries. No new errors does not prove that every task is healthy; each report states its coverage.
- WeChat notifications depend on the reply context accepted by WeChat. If sending is temporarily protected, send ClawBot a new message and observe recovery.
- Real mobile, Agent and ClawBot experience remains subject to user acceptance.
