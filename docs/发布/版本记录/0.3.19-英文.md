# WeRelay 0.3.19

Release date: 2026-10-21

## Repository and privacy cleanup

- The open-source application and brand website are maintained separately. Website copy, demonstration materials, and website-only production tools are no longer distributed with application source or installation packages.
- The mobile task interface, WeChat connection, public relay, self-hosting examples, and user documentation remain available. Installing and using WeRelay does not require access to the website source.
- A personal username in a test fixture has been replaced with a generic example. Additional checks prevent private website materials from entering public snapshots.
- Documentation now explains the boundary between the open-source application and the private website.

## Security maintenance

- Updated an underlying component to fix a crafted-URL issue that could bypass static-file access restrictions. No affected serving path or evidence of exploitation has been identified in WeRelay.
- Task, messaging, approval, and connection behavior is unchanged; no configuration changes are required.

## Usage

- This release combines repository cleanup with a dependency security patch; product functionality is unchanged from 0.3.17. No new login, pairing, or task migration is required.
- This publication updates GitHub only. It does not install software or restart desktop or public services; existing running versions remain unchanged.

## Known limitations

- This cleanup does not rewrite past commits or replace older installation packages. Historical non-sensitive demonstration materials remain accessible.
- The WeChat reply-context limitations, long-term real-time connection observation, and remaining acceptance gaps documented for 0.3.17 still apply.
- New features that have not completed experience acceptance are not included.
