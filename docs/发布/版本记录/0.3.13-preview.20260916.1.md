# 0.3.13 体验更新

本次是集中体验候选，尚未发布为 GitHub 正式版本。

## 审批和提问不再跑到别的任务

- 修复了 A 任务的审批或提问出现在 B 任务里的问题。现在每个任务只显示属于它自己的待确认和待回答内容，在某个任务下回复也不会回答到别的任务。
- 这个修复同时作用于网页任务台和微信 ClawBot。

## 进入任务直接看到最新消息

- 修复了打开任务时停在最顶部、需要不断往下滚很久才能看到新消息的问题。现在进入任务会直接落在最新内容上。

## 消息更清爽

- 一轮回复里的模型名和更新时间只在整轮末尾显示一次，不再每一小段都重复一遍。
- 任务运行中只显示不断更新的时间，模型名等到这一轮结束再显示。
- 任务结束后不再一直显示「正在规划」的省略号动画。
- 进展列表与下方正文之间的空隙收紧，阅读更连贯。

## 发出的消息会排队

- 任务正在处理时发出的消息，现在会进入输入框上方的「待发」列表，不再直接混进正文气泡里让人看不出它在等待。
- 待发列表与输入框连成一体，上面两角圆角、下面与输入框相接。
- 任务空闲时发出的消息仍然直接显示为正文，不会无故滞留。

## 品牌与开屏

- 任务台的品牌字标换成与官网同一张字标图（黑字配绿色弧线），在亮色和暗色模式下都清晰可读。
- 开屏页面更简洁：等待连接时的说明不再重复同一句话，并带有一个随主题自动切换的思考动画。

## 使用说明

无需重新配对。本次不改变原任务身份，也不会为了恢复而另建替代会话。微信上下文失效、电脑睡眠和网络断开仍可能影响消息送达；实际微信收发、长时间运行及睡眠唤醒仍需体验验证，不承诺所有断线或发送问题都已消除。
