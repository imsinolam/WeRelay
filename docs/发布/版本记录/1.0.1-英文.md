# WeRelay 1.0.1

Release date: 2026-11-07

## What's new

- Long messages on the phone no longer make the composer collapse while you type. Text, cursor position and scrolling stay stable while a Chinese input method is composing.
- The end of a long paragraph remains visible, and editing in the middle of the text no longer jumps back to the bottom.
- Model choices appear faster when creating a task and reuse options that have already loaded. Switching terminals no longer borrows another terminal's model selection.
- If the current connection cannot change models, the page says so instead of showing a choice that will not take effect.

## Upgrade

Update both the local background program and the public Relay. Reopen the mobile page to load the new version. Existing WeChat pairing, task history and access passwords are retained; no Agent reinstall or terminal reconfiguration is required.

## Known limitations

- Whether models can be changed still depends on the terminal and connection. The page explains when it is unavailable.
- WeChat notifications require an accepted reply context. After a long idle period, send ClawBot a fresh message if needed.
- The user confirms real Agent and ClawBot messaging after upgrading.
