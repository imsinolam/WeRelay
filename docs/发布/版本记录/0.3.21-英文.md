# WeRelay 0.3.21

Release date: 2026-10-24

## What's new

- ClawBot now checks both stable and prerelease versions, and clearly reports the installed version, the available version, and how to update.
- WeRelay downloads and installs the matching version only after you reply "更新" or send `/update` in ClawBot. Replying "检查更新" only checks; it never installs anything.
- Internal reviews and subtasks on the computer no longer appear in the normal task list, search, or recent completions, and no longer send "task completed" notifications.

## Fixes

- ClawBot used to miss prerelease versions because it only checked the latest stable release. It now checks both published kinds, compares complete version identities correctly, and never downgrades an installed newer version.
- Normal work requests such as "update the web page" or "publish a new version" are no longer mistaken for a WeRelay update command.
- Downloading, building, and installing an update no longer blocks WeChat message processing. If installation fails, the previous program and commands are retained and the failure is reported.
- Internal reviews and subtasks no longer interrupt WeChat when they finish, while real approvals and questions that need you remain available and actionable.
- Internal tasks that were already shown no longer take over another task's number, and old page caches or completion history do not bring them back into the list.

## Upgrade notes

- WeRelay does not restart itself after installation. To start using the new version, send an explicit "重启" in ClawBot or restart WeRelay from the computer-side instructions.
- The update-check capability takes effect only after this version is installed on the computer. Older installations do not gain it just because a new release exists on GitHub.
- No new login, pairing, or migration is required; existing tasks and messages continue to work.

## Known limitations

- Proactive WeChat notifications still depend on WeChat accepting the current reply context. After a long period without interaction, proactive delivery may be unavailable until you send ClawBot a normal message.
- Automatic updates work only for a standalone global installation managed by WeRelay. Source checkouts, linked directories, or installations whose location cannot be confirmed are refused.
- A hard power loss or forced process termination can prevent the automatic rollback from running, although the pre-install backup remains available.
