# 0.3.13 experience update

This is an experience candidate, not a formal GitHub release.

- Keep approvals and questions with their own task: no more pending confirmations or questions from one task appearing under another, in the web console or WeChat ClawBot.
- Land on the newest message when opening a task instead of stopping at the very top.
- Show the model name and updated time once per turn instead of repeating them for every segment; hide the model name while a turn is still running.
- Stop the "planning" dots animation as soon as a turn settles.
- Tighten the spacing between the progress list and the body text below it.
- Queue a message sent while a task is busy into the pending list above the composer, attached to the composer with only its top corners rounded; idle tasks still show the message directly as a bubble.
- Use the same WeRelay wordmark image as the website, readable in both light and dark mode, and simplify the boot screen with a theme-aware thinking animation.

No new pairing is required. Original conversations are preserved. WeChat context validity, sleep and network failures still need real-world acceptance; this candidate does not promise to eliminate every delivery or connection failure.
