# 0.3.13 体验更新

本次是集中体验候选，尚未发布为 GitHub 正式版本。

## 微信操作更清楚

- 任务列表与操作说明分开发送，先看任务，再看怎么操作；长列表保持顺序，任务编号不变。
- Grok 的旧任务不再因为后台更新资料而错误排到前面，列表按真实任务活动排序。

## 网页消息更连贯

- 发出的消息在终端接收和开始处理期间继续保留，不再忽然消失；真实记录到达后自然衔接，避免重复。
- 可以看到其他 Codex 任务发来的消息，并区分来源和收到时间。
- 新建任务时可以预选受支持的模型和推理强度；设置未确认生效时保留消息并提示重试，不悄悄按错误设置发送。

## 连接更稳

- 电脑端忙于处理内容时，DeepSeek Harness 的连接保活独立进行，减少误断线。
- 连接稳定恢复后，不再一直沿用此前较长的重试等待。

## 使用说明

无需重新配对。本次不改变原任务身份，也不会为了恢复而另建替代会话。微信上下文失效、电脑睡眠和网络断开仍可能影响消息送达；实际微信收发、长时间运行及睡眠唤醒仍需体验验证，不承诺所有断线或发送问题都已消除。
