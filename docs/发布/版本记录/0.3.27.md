# WeRelay 0.3.27

更新日期：2026-10-31

## 这次更新

- 修复网络卡顿后任务短链接迟迟无法恢复的问题；网络恢复后，再次获取任务列表或发送通知时会及时重新尝试。
- 加强短链接确认，避免把代理登录页等异常返回当成成功，也不会把尚未可用的短链接发到微信。
- 短链接异常时保留清晰提示，原任务、消息内容和微信配对保持不变。

## 升级说明

无需重新配对或修改设置，原有任务链接继续有效。

## 已知限制

实际网络不可用或微信回复上下文已失效时，仍可能暂时无法发送；本次改进不代替网络恢复或微信上下文刷新。真实 Agent 与 ClawBot 的交互由用户更新后自行体验。
