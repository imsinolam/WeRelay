# WeRelay 0.3.8

发布日期：2026-09-04

## 这次更新

- 手机网页发送消息后，即使关闭页面，电脑端也会继续处理和投递；同一任务连续发送多条消息时会保持原来的先后顺序，不再因为网络等待而前后颠倒。
- 手机网页的模型选择改为先选模型来源、再选具体模型，模型较多时更容易找到目标；推理强度和访问权限合并到一个简洁入口，当前选择会直接显示为“中 · 完全访问”等易读状态。
- 输入区域增加柔和的流动光效，并继续尊重系统的“减少动态效果”设置。

## 修复的问题

- 修复了消息在页面关闭、网络短暂中断或电脑端响应较慢时可能消失、重复提交或顺序错乱的问题。暂时无法提交的消息会保留在原任务中，支持复制和重新提交；多次失败时还会通过 ClawBot 提醒。
- 修复了手机网页模型的二级菜单有时点不开的问题；没有手动选择推理强度时，会明确显示“跟随会话”。
- 修复了切换终端或重新连接时，已经显示的任务正文会短暂变成空白的问题。现在会保留原内容并在后台更新，最新内容准备好后再替换。

## 升级说明

- 升级后无需重新登录或修改配置。
- 为确保页面使用新版交互，已经打开的手机网页会在检测到版本变化后自动刷新。

## 已知限制

- 离开网页后的持续投递仍要求电脑端 WeRelay 保持运行；电脑暂时离线时消息会保留并等待恢复连接。
- 可选择的模型、推理强度和访问权限仍以当前终端及任务实际支持的范围为准。
