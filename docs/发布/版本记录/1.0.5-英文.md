# WeRelay 1.0.5

Release date: 2026-11-15

## What's new

- Message journal refreshes use less data. When nothing has changed, the page confirms it is current instead of transferring the whole message page again.
- If saving journal sources times out, WeRelay checks what was actually saved on the computer. A confirmed save continues into the journal instead of being reported as a failure.
- Saving the same sources again no longer clears the existing journal or restarts the first scan.

## Upgrade

Update both the local program and public Relay, then reopen the mobile page. Existing source permissions, task history and access passwords remain unchanged.

## Known limitations

- The journal shows supported sources from the last 30 days, not complete history.
- New journal content still requires the computer to be online. Existing data remains visible while the page reports a retryable connection problem.
- Real mobile, Agent and ClawBot acceptance remains with the user.
