# WeRelay 0.3.21

发布日期：2026-10-24

## 这次更新

- ClawBot 现在会同时检查正式版和预发布版，并明确告诉你当前安装版本、可更新版本以及应该怎样更新。
- 在 ClawBot 中回复“更新”或发送 `/update`，WeRelay 才会下载并安装对应版本；只回复“检查更新”不会安装任何内容。
- 电脑上的内部评审和子任务不会再出现在普通任务列表、搜索或最近完成里，也不会再推送“任务已完成”提醒。

## 修复的问题

- 以前 ClawBot 可能只发现正式版，错过已经发布的预发布版；现在两种已发布版本都会检查，并按正确顺序判断新旧，不会把已安装的新版本降级。
- 普通聊天里出现“更新网页”“发布新版本”等正常工作要求时，不会再被误判成更新 WeRelay 的指令。
- 更新的下载、构建和安装不会卡住微信消息收发；安装失败时会保留原来的程序和命令，并提示更新没有完成。
- 内部评审和子任务完成时不再打扰微信，但真正需要你处理的审批和问题仍会正常送达，而且可以直接操作。
- 已经显示过的内部任务不会重新占用其他任务的编号；旧页面缓存和历史完成记录也不会把它们重新带回列表。

## 升级说明

- 安装本版本后，WeRelay 不会自行重启；需要让新版本真正运行时，可以在 ClawBot 明确发送“重启”，或按电脑端提示重启 WeRelay。
- 更新检查能力需要先安装到电脑上的 WeRelay 才会生效，旧版本不会因为 GitHub 出现新版本而自动获得这项能力。
- 升级后无需重新登录、重新配对或迁移已有任务和消息。

## 已知限制

- 微信主动通知仍依赖微信认可当前的回复上下文；如果长时间没有互动，主动通知可能暂时不可用，此时先给 ClawBot 发一条普通消息即可恢复。
- 更新只支持由 WeRelay 自己管理的独立全局安装；从源码运行、通过链接目录运行或无法确认安装位置时，会明确拒绝自动替换。
- 强制断电或进程被强制结束时，无法保证自动回退已经执行，但安装前保留的回退备份仍然存在。
