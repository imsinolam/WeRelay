# WeRelay 1.0.6

发布日期：2026-11-17

## 这次更新

- 修复新版 Codex 桌面端接收手机消息时的兼容问题，继续使用原任务，发送状态与桌面保持同步。
- 手机输入和编辑消息更稳定，发送图片后保留预览，刷新消息时不再丢失附件显示。
- 消息日历更适合手机阅读，筛选、切换日期和来源选择更清楚；没有消息时会说明当前状态。
- 消息日历没有变化时只确认更新状态，减少重复下载；保存来源超时后会核对实际结果，重复保存也不会清空已有内容。
- 增加供维护者使用的失败巡检工具，帮助查看近期消息送达问题；报告不包含聊天正文、原始错误或本地路径。

## 升级说明

本机程序和公网 Relay 一并更新后，重新打开手机网页即可使用。访问密码、消息来源授权和原任务历史保留，无需重新设置。

## 已知限制

- 电脑离线时无法读取新消息；消息日历只显示已授权来源最近 30 天的用户消息。
- 微信通知仍受微信认可的回复上下文限制，遇到发送保护提示时可向 ClawBot 发送一条新消息后再观察。
- 真实手机、Agent 与 ClawBot 使用体验由用户确认。
