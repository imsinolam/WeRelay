# 0.3.13 体验更新

本次是集中体验候选，尚未发布为 GitHub 正式版本。

## 待发送消息不再永久滞留

- 修复了「待发送」列表里挂着一条很久都不消失的消息、而且删除、编辑、引导三个按钮都没有反应的问题。
- 现在等待确认超过 1 小时仍未得到终端确认的消息，会离开待发送列表并回到正文，内容完整保留，可以复制或重新提交。不会再无限期占位。
- 删除和编辑对这类消息也能用了：删除会取消这条本地待发送（不会重复发送），编辑会把内容取回输入框，改完可以重新发出。
- 已经在终端排队、有明确队列编号的消息不受影响，仍按原来的方式自动消失。

## 短链接可以正常打开了

- 修复了以 `-` 或 `_` 结尾的微信任务短链接，在微信里不会被整体识别为链接、点开无法访问的问题。
- 新的短链接只使用字母和数字，不会再被微信截断。
- 此前已经发出的旧链接仍然可以正常打开，不需要重新获取。

## WorkBuddy 的任务列表能看到

- 修复了 WorkBuddy 显示在线、任务台却看不到任务列表的问题。
- 现在即使守护进程尚未为它建立连接，也能先读到任务列表；进入后会自动建立连接。
- 未连接时只提供查看，重命名、新建、发送等操作仍需建立连接后进行。

## Grok 列表可以新建任务

- 修复了 Grok 的任务没有项目归属时，列表里缺少新建任务入口的问题。
- 现在这类终端在「最近」分组右侧也会显示新建按钮。

## 使用说明

无需重新配对。本次不改变原任务身份，也不会为了恢复而另建替代会话。微信上下文失效、电脑睡眠和网络断开仍可能影响消息送达；实际微信收发、长时间运行及睡眠唤醒仍需体验验证，不承诺所有断线或发送问题都已消除。
