# WeRelay 0.3.29

Updated: 2026-10-31

## Changes

- WeChat task-list web links open the task board instead of selecting a task from the list.
- The mobile sidebar now has a horizontally scrollable Agent icon row with full names and clearer selection and edge treatments.
- Includes recent task-board improvements: message records and statistics, project filtering, inline previews, and persistent connection retry feedback.
- Pi Desktop can connect to its original tasks through a dedicated plugin. Completed tasks regain their composer, while unconfirmed sends preserve their original identifier and attachments.
- Task short links recover promptly after network stalls and require acknowledgement before delivery. Optional Android system notification support remains disabled until configured.

## Upgrade

Refresh the web page; no WeChat pairing changes are needed. First-time Pi Desktop plugin use requires user installation and permission. Android push requires a matching client and vendor configuration.

## Limitations

- Network outages and expired WeChat reply contexts can still prevent delivery; not all connection issues are claimed fixed.
- Android vendor push has not been verified with production credentials and a real device and is not enabled without configuration.
- Live Agent, WeChat messaging, and approval acceptance is performed by the user after updating; no automated messages are sent for this release.
