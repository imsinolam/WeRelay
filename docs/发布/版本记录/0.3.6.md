# WeRelay 0.3.6

发布日期：2026-08-27

## 修复的问题

- 修复从手机网页切换到历史内容很多的 Codex 任务后，本机网页、设备在线状态和消息发送可能长时间没有响应的问题。
- WeRelay 现在只读取该任务最近新增的内容，不再从头重新处理整份历史；原任务身份、最新回复和完成通知保持不变。

## 升级说明

- 建议已经安装 0.3.5 的用户直接升级到 0.3.6。
- 请同时升级电脑端 WeRelay 和公网 Relay，并安全重启现有服务。
- 已有微信登录、网页访问密码、设备配对、任务记录和短链接无需重新配置。

## 已知限制

- 首次打开历史特别长的任务时，完整旧消息仍会按需分批加载；这不会阻塞设备在线和新的消息发送。
- 桌面 Agent 或公网 Relay 离线时，恢复连接前不能执行新的远程操作。
