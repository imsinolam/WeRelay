# WeRelay 0.3.31

发布日期：2026-11-05

## 这次更新

- 手机网页可以为任务的下一条消息选择模型和推理强度；发送后所选设置会保留到电脑端确认，不会先跳回旧选项。
- 手机和电脑上已有新消息、任务变化或运行状态变化时，网页会自动更新当前任务，并在使用其他任务时提前准备最近常看的任务，减少来回切换时的等待。
- 手机侧边栏的终端排序更贴近最近使用情况，选中的终端图标保持清晰、平衡。
- 主任务的对话末尾可以展开“子任务”，以只读方式查看相关内部任务内容。查看子任务不会切换当前任务、清空草稿或向子任务发送消息。

## 修复的问题

- 手机发送模型切换后，界面可能过早显示旧模型，让人误以为选择没有生效。
- 桌面端应用处于正常退出或需要重新连接时，部分提示不够准确；现在会说明实际状态和下一步。
- 部分 DeepSeek Harness、OpenCode 和 Codex 的内部子任务可能出现在普通任务列表里，或被当成独立任务打开。现在会保留在主任务关系内，审批仍可正常处理。

## 升级说明

手机网页刷新即可载入新界面。本机后台程序需要更新后重新连接；不需要重新配对微信，也不需要重新安装正在使用的 Agent。

## 已知限制

- 子任务仅在电脑端提供可靠父子关系时显示；原始终端未连接或关系记录不可读时，会显示读取失败并允许重试。
- 手机选择模型和推理强度依赖对应终端支持；终端不支持时会明确提示，而不会静默改用旧设置发送。
- 本版本没有改变微信主动推送需要有效回复上下文的限制，也没有改变真实 Agent 和微信链路的既有使用规则；升级后由用户自行体验这些流程。
