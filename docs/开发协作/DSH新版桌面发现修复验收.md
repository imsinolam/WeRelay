## 根因与范围

现场旧 DSH Desktop 2.0.13 与新 DeepSeek Harness 0.2.1-rc.2 同时存在。旧应用没有可用的默认接口，新应用的包内 Host 使用动态回环端口，另有 inspector 监听。旧发现逻辑只识别旧应用，因此回退旧端口并报连接拒绝。

本修复共用两代应用进程分类，从新版真实 Host PID 发现动态回环接口并排除 inspector。已检测新版但接口未就绪或不唯一时明确失败，不转到旧应用或独立网页 owner；显式配置 URL 仍优先。旧版认证与协议保留，不修改用户模型、设置或会话内容，不自动重启应用。
