# 任务台的模型和推理强度

在输入框下方选择模型，或打开“推理 · 权限”菜单调整推理强度。可选项来自电脑终端实际提供的能力；模型不支持推理、未完成登录或终端版本过旧时，会说明原因，不展示虚假的档位。

## 支持范围

| 终端 | 模型与推理设置来源 | 注意事项 |
| --- | --- | --- |
| Codex | 原任务的模型、推理设置接口 | 沿用现有支持 |
| DeepSeek Harness | 原终端的会话设置接口 | 沿用现有支持 |
| Pi | 原 Pi 进程的模型注册表和思考档位 | 已打开的旧窗口需在更新后执行 `/reload`；只有支持思考的模型提供强度选项 |
| Grok、CodeBuddy | 原共享进程提供的模型目录与会话配置选项 | 推理选项取决于终端版本与所选模型 |
| Claude Code、TClaude | 原终端的 `/model`、`/effort` 菜单 | 要求原生菜单提供“仅本会话”选项；旧版本需更新，不使用会修改全局默认值的确认方式 |
| reasonix | 当前原任务的 `/models`、`/model`、`/effort` 服务接口 | 原终端必须提供这些接口；切换时校验原任务身份 |
| WorkBuddy | 桌面原任务的模型及配置接口 | 需要已接入桌面主进程；设置后回读确认，不把接口空成功当作切换成功 |
| OpenCode | 同一个服务的模型目录、任务元数据及原生消息插件 | 修改下一条消息的实际模型与变体；原 TUI 模型选择器的选中项不保证立即跟随变化；任务台设置生效期间，电脑的新消息也以任务台选择为准 |
| Shell | 无模型设置 | 普通命令行不是模型 Agent，不伪造模型或推理选项 |

## 行为边界

- 设置只作用于选中的原任务，不新建另一份会话或另起一个 Agent 进程。
- 当前任务正在执行、等待审批，或电脑输入框有未发送内容时，可能暂时不能修改。网页会保留原因，完成后可以重试。
- Claude/TClaude 的首轮设置读取会短暂打开原终端菜单；电脑端开始输入时会取消远程菜单操作，不吞掉本地按键。
- OpenCode 的设置保存在原任务的元数据中，由当前服务内的消息插件统一应用到网页和电脑的新消息，不改电脑全局模型配置。安装后需要正常重新启动这一服务才能加载插件。
- 这些说明对应本地开发实现。功能需统一发布后才能在已部署版本使用；未实测的终端版本不承诺兼容。
