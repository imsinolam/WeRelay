# 5 分钟启用局域网移动网页

本页适合**没有公网服务器**的新用户。WeRelay 的 daemon 内置移动网页服务，不需要另装 Web 服务，也不需要公网隧道。

## 你会得到什么

- 手机和电脑处于同一可互访局域网时，可以打开 WeRelay 网页；
- 网页、微信 ClawBot 和电脑端 Agent 操作的是同一批真实任务；
- 电脑不会因为启用网页而向公网开放通用 HTTP/TCP 隧道；
- 电脑休眠、关机或 daemon 停止后，网页不能继续操作任务。

## 第一步：安装并完成微信登录

WeRelay 需要 Node.js `>= 24`，并且至少一个受支持的 Agent 已经安装、登录并可正常使用。

先按 [从 GitHub 安装与更新 WeRelay](GitHub源码安装与更新.md) 完成安装，然后执行：

```bash
node --version
werelay-setup
```

`werelay-setup` 只负责微信登录，**不会单独启动移动网页**。

## 第二步：启动 WeRelay daemon

进入希望 WeRelay 绑定的项目目录：

```bash
cd /path/to/your/project
werelay --idle-start --no-open
```

推荐首次使用 `--idle-start --no-open`：

- 先让微信和移动网页上线；
- 不自动恢复上一次终端；
- 不自动打开可见终端窗口；
- 不会自动启动 ChatGPT 等桌面应用。

如果希望启动时立即连接某个 Agent，也可以使用：

```bash
werelay --adapter codex
```

## 第三步：确认局域网网页已经启动

成功后终端会显示类似：

```text
WeRelay mobile web is ready at http://192.168.1.20:4396
```

本机健康检查：

```bash
curl -fsS http://127.0.0.1:4396/health
```

预期：

```json
{"ok":true}
```

默认端口是 `4396`。如果端口被占用，WeRelay 会继续尝试 `4397`、`4398` 等后续端口。实际地址以日志为准：

```bash
grep 'codex_mobile_started' ~/.werelay/bridge.log | tail -1
```

## 第四步：第一次设置移动网页密码

终端启动时打印的是局域网基础地址；为了防止局域网内其他人抢先设置密码，**首次设置密码必须从 ClawBot 返回的授权任务链接进入**。

在 ClawBot 中：

1. 发送“任务”；
2. 回复序号，进入一个真实任务；
3. 发送“状态”；
4. 打开状态消息中的移动网页链接；
5. 设置一个只用于移动网页的访问密码。

任务完成通知中的网页链接也可以用于首次设置密码。setup 链接包含短期敏感授权，不要转发、截图或提交到 issue。

设置完成后：

- 后续任务链接不再携带 setup 授权；
- 打开局域网基础地址时使用刚设置的密码登录；
- 密码和登录状态保存在本机 `~/.werelay`，不要上传或公开。

## 第五步：手机验收

确认手机和电脑连接同一个可互访网络，然后完成以下检查：

1. 手机能打开登录页；
2. 登录后能看到 Agent 和任务列表；
3. 进入一个任务，能读取最近消息；
4. 从网页发送一条带当前时间的测试消息；
5. 电脑端同一个任务能看到这条消息；
6. Agent 回复后，网页能在同一个任务中看到回复。

只看到历史但消息没有进入电脑端，不算验收通过。

## 常见问题

### 手机打不开地址

依次检查：

1. 手机和电脑是否处于同一 Wi-Fi；
2. 是否使用访客 Wi-Fi、企业客户端隔离或 VPN；
3. macOS、Windows 或 Linux 防火墙是否允许 Node.js 接收入站连接；
4. 实际端口是否已经从 `4396` 递增；
5. 微信内置浏览器是否限制局域网 HTTP，可尝试系统浏览器；
6. 电脑切换 Wi-Fi 后是否仍在使用旧 IP，必要时重启 daemon 并获取新链接。

### 页面要求“从微信重新打开最新链接”

这表示移动密码尚未设置，而当前 URL 不包含有效 setup 授权。先在 ClawBot 中进入一个任务，再发送“状态”，使用返回的新链接。

### 本机健康检查失败

查看：

```bash
tail -100 ~/.werelay/bridge.log
```

重点查找：

```text
codex_mobile_started
codex_mobile_start_error
```

更多问题见 [问题排查](问题排查.md#werelay-移动网页打不开)。

## 需要外网网页时

微信 ClawBot 本身仍可在外网使用；只有移动网页需要同一局域网。如果希望手机在外部网络通过 HTTPS 打开网页，请继续阅读：
