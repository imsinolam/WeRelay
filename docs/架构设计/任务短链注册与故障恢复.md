# 任务短链注册与故障恢复

## 链路与不变量

电脑端根据设备密钥、终端和原任务 ID 生成确定性别名，通过已认证的 HTTPS 注册接口将映射保存在 Relay；收到 `{ "ok": true }` 确认后才向微信发送十字符短链。任务身份始终是 `adapter + sessionId`，不会为生成链接切换终端、打开任务或创建替代会话。

任务台网页、设备 WSS 和短链注册是不同请求。任务列表读取成功不代表短链注册成功，WSS 正常也不能代替注册接口验活。注册不需要 Agent 在线，已持久化的映射在电脑离线时仍应能跳转至原任务入口。

## 任务列表与单条任务通知的入口区别

- ClawBot 任务列表末尾统一发送固定短入口 `/b`，打开 `/?view=board` 看板，不选择任何任务或限定终端。全局、终端筛选、分页、搜索列表都使用同一入口。
- `/b` 在局域网服务和公网 Relay 均直接解析，不依赖电脑在线、任务枚举或短链注册，因而不受任务别名注册失败影响。它只打开页面，不绕过网页登录和 API 鉴权。
- 跳转只允许保留现有 `key` / `setup` 认证参数，忽略传入的任务、终端与其他参数；已设置访问密码时生成的入口不携带认证值。
- 单条任务的完成、审批、发送反馈等通知仍使用原有任务短链，准确进入原任务，不改为看板。
- 验收增加 `test/relay/relay-board-link.test.ts`，覆盖本地/公网、电脑离线、认证参数保留及任务选择参数隔离。

## 曾出现的恢复缺口

旧客户端只限制了微信发送前等待确认的时间，没有限制注册 HTTP 请求本身。若注册请求悬挂，其 pending 状态会一直被后续请求复用，无法发起新尝试。正常失败又会退避至最长 30 秒，但微信发送只等待 5 秒：网络已经恢复时，用户再次获取任务仍可能超时。

这两种情况必须通过回归测试保留，不能通过延长微信等待时间、隐藏警告或直接输出未注册别名处理。

## 恢复契约

- 单次注册及其确认正文读取默认最多 2 秒，独立于整个客户端的关闭信号；即使测试传输忽略取消，也必须结束本次尝试。
- 后台仍按 1 秒至 30 秒有界退避重试；用户实际请求单条任务短链时，立即唤醒退避中的注册。同一别名只保留一个有效在途尝试，不与并发发送重复注册。
- 调用方等待确认仍有自己的截止时间；超时不能清除后台恢复状态。迟到的旧请求不能把后续尝试标记为成功。
- 只有 HTTP 成功且 JSON 明确包含 `ok: true` 才确认，不能把代理登录页或普通 HTML 200 当作注册成功。不跟随注册接口重定向。
- 客户端关闭时取消请求、移除重试定时器并唤醒等待者；关闭后不能生成新链接或接受迟到确认。
- 注册失败只记录 `timeout / network / http / protocol`，HTTP 错误可附状态码。不得记录设备密钥、设备 ID、任务 ID、别名、认证参数、原始异常或响应正文。
- 仍不向微信输出未确认的短链或带认证参数的长链接。持续离线时无法保证注册成功，应如实提示，不承诺网络故障被代码消除。

## 排查与验收

1. 先确认正式域名当前 DNS 解析及实际部署目标，不能用旧服务器的健康状态代表正式入口。
2. 检查 `wechat_task_short_link_unavailable` 附近时间与公网超时、电脑睡眠等证据。旧日志没有失败分类时，不把网络错误或某个终端升级说成已证实的唯一原因。
3. 验证已认证连接检查；使用一个已存在任务验证合法注册返回 200、别名请求返回 302，且跳转目标仍是该终端和原任务。不发送 Agent 消息，不输出认证值或私人任务内容。
4. 注册 401/403 优先核对配对；404 核对服务版本与路由；5xx 核对 Relay 状态文件私有权限、服务身份、受限写入路径及服务日志。不扩大目录权限，不关闭鉴权。
5. 测试入口：`test/relay/relay-task-links.test.ts`、`test/relay/relay-integration.test.ts`、`test/daemon/task-list-link.test.ts`。覆盖悬挂恢复、退避唤醒、并发合并、错误确认、迟到响应、关闭、旧别名和重启后映射。

开发完成与在线部署分开：开发 Agent 提交并登记，发版 Agent 按统一版本流程安装同一包；不能只改工作区就称后台已修复，也不直接覆盖已安装的 dist。
