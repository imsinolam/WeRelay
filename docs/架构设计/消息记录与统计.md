# 消息记录与统计

## 目标与边界

设置新增「消息记录」，统一查看 ClawBot、网页任务台交给 Agent 的消息。记录只描述消息交付，不把已提交或排队等同于任务执行完成，不统计 Token 或费用。微信控制命令、审批操作与 Agent 自己产生的回复不混入任务消息统计。

## 实施顺序

1. 增加工作区级私有账本：稳定消息 ID、来源、Agent、任务、摘要、附件数量、尝试次数、状态时间线；提供筛选、统计、保留、导出和清理。
2. 网页待发送箱在持久化状态变化后同步账本；ClawBot 在实际交给 Agent 的统一入口记录尝试、接受、排队或失败。重试复用原 ID，不重复计数。
3. 增加鉴权设置 API，读取账本不连接 Agent；设置页展示筛选、概览、详情、原任务入口及隐私策略。
4. 使用临时目录、假运行时和合成网页检查幂等、重启、回执、失败、隐私、鉴权、筛选和手机布局。不向真实 Agent 或微信发送测试消息，不部署。

## 保存与隐私

- 电脑工作区私有目录保存，文件 0600、目录 0700；不进入 Git，不上传独立分析服务。远程查看仍经过既有 HTTPS 中继、配对与登录鉴权。
- 默认记录脱敏摘要；可选择不保存文字或保存脱敏正文（每条最多 4000 字符）。不额外保存附件内容、附件路径、微信身份或认证配置。消息文字本身仍可能含路径或个人信息；常见密钥尽力脱敏，不是绝对保证，导出前需自行审查。
- 默认保留 30 天、最多 5000 条、账本最多约 8 MiB；先达到的限制优先。可选择 7/30/90 天和 500/2000/5000 条。每条时间线有界，旧事件折叠不无限增长。
- 关闭记录不影响发送。切换为更严格的文字策略会同步清除已保存的对应文字；恢复保存不追溯补回。清空只删除账本，不删除真实会话、待发送箱、附件或重试任务。
- 网页旧待发送箱只导入仍存在的快照，标记「历史快照」，不伪造过去的过程；ClawBot 不从旧运行日志推算。统计明确显示当前保留范围、历史快照数和启用时间，不称为历史累计总量。

## 验收口径

一条消息对应一条记录，重试增加尝试数而非消息数；网页新建临时任务转为真实任务时身份不变。排队、提交、确认送达与失败分别可查。ClawBot 原生接口返回只证明提交，无法确认收件时不得显示已送达。清理与关闭记录不改变发送；API 需要登录、禁止缓存敏感查询；筛选和分页在账本内完成，不枚举或唤起真实 Agent。

## 紧凑筛选与任务预览

- 默认只展示来源、交付分类、搜索与常规尺寸查询按钮。时间、Agent、具体状态、消息类型和自定日期放入「更多筛选」，折叠时仍显示当前已应用条件。
- 交付状态归为「处理中」（收到、待发送、发送中、重试、排队）、「已发送」（提交、确认送达）、「需关注」（未确认、失败）、「已结束」（取消、控制消息已处理）。具体状态仍可在更多筛选和交付详情中查询；分组筛选在分页与统计前生效，导出口径相同。
- `active` 等原生运行状态归一为「任务进行中」，与交付状态并列而不互相覆盖。仅使用已有 slot、缓存目录和运行信号，不因读取账本连接、切换或枚举 Agent；缺少信号不伪称完成。任务运行态是读取时的补充信息，不写入持久交付账本。
- 点击记录原地打开原生 dialog 浮层；通过指定 adapter 的只读最近 30 条消息接口预览，复用通用消息气泡和 Markdown。既有任务、终端、地址和设置筛选保持不变；未连接时原地提示与重读，不偷偷启动 Agent。
- AI 回复默认仅显示末尾三行（长行再按三视觉行限制），可展开完整回复并收起；用户消息不折叠。关闭、切换分类或离开设置时销毁浮层，迟到读取不回写其他预览；失败可原地重新读取。图片可另页打开原受鉴权资源。

## 按所属项目查看

- 首行提供「所属项目」选择，消息来源移入更多筛选，保持首屏紧凑。项目选项带消息数量，可与来源、Agent、交付状态、时间组合；记录行和任务预览同时展示项目名。
- 项目归属只用同 adapter、同 thread 的已有任务缓存、任务快照和目录缓存，不扫描聊天正文、不以任务标题或同名项目猜测，也不连接或启动 Agent。未知归属进入「未归属项目」。缓存尚无元数据时，可先使用其余条件查看；正常任务目录刷新后再次查询即可补充归属。
- 有 cwd 时以规范化目录摘要为稳定项目键，跨 Agent 同目录可归一，同名但不同目录不混合；只有原生 projectId 时按 adapter 隔离。账本保存不透明项目键和最多 120 字符项目名，不额外保存目录路径。项目名仍属于导出时需审查的信息。
- 已知归属随发送状态保存，历史记录查询时可用现有缓存补全，并在启用记录时持久化以跨重启保留；不复活清空记录，不补回已删除正文。暂停期间只做内存展示，不保存新归属。
- 项目筛选在分页和统计之前生效，导出覆盖筛选后的全部保留记录。项目选项数量基于其他已应用条件、但不受当前所选项目限制，方便切换；同名项目追加短标识区分。

## 风险与回滚

记录失败不能阻塞消息交付，设置页要显示记录不可用，不能静默声称记录完整。账本追加写入并定期压缩，避免每次轮询重写全部历史。回滚代码不删除账本；旧版本继续使用原待发送箱与会话，账本没有执行控制权。
