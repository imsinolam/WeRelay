关系图明确表达：

1. 电脑上的 Agent 持有任务、项目、上下文和工具。
2. WeRelay 连接原任务，不成为第二个 Agent。
3. 微信 ClawBot 接收结果、查找任务、回复和处理审批，不需要云服务器。
4. WeRelay 任务台是另一个入口：同一可互访 Wi-Fi 直连电脑；外网访问需自建 HTTPS 服务器和访问认证。
5. 双向箭头表达结果送到手机、指令与审批回到原任务；电脑仍需在线。

图中列出当前公开版本支持的九种 Agent。Pi 等只在官网预览中演示的接入不写成公开版本已经支持。

## Agent 标志

沿用官网已审核的应用标志：Codex 使用 ChatGPT 图标；Grok 使用 Grok 标志，不使用 Grok Bot 图标。Claude Code 使用官网现有标志。其余对象使用同一批官网素材，不手绘替代。

这些标志用于辨认连接对象，权利属于各自品牌，不表示这些品牌为 WeRelay 背书。

## 隐私与变更

- 图中只有固定文案与品牌资产，没有账号、私有任务、凭据、设备地址或日志。
- 新增位图在隐私检查中按文件路径和 SHA-256 登记；图片变化需重新审查并更新登记，不能放开整个图片目录。
- 用户明确批准公开的官网 HTTPS 根地址只允许出现在指定的介绍文件；任务链接、API 路径、其他个人域名和真实服务器 IP 仍禁止进入公开文件。
- 本次更新仅涉及品牌素材与说明，不改变软件版本、安装命令和运行行为。
