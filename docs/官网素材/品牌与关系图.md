## 视频与截图

[60 秒产品演示](https://werelay.sinolin.com/__website/assets/media/WeRelay-60s-Film.mp4)使用官网现有的公开 MP4，不把大体积视频重复提交到仓库。README 使用带播放图标的横屏封面链接到视频，不依赖 GitHub 会移除的自定义视频标签。

视频是模拟演示，包含预览接入；它不代替 README 的正式支持范围。截图采用当前官网导出的原生呈现模板，不重新手绘聊天或任务台界面。ClawBot 保留无头像模式、AI 气泡、导航栏及统一 1.4 行距；任务台保留原生任务看板、消息导航、输出折叠与输入框样式。四张截图使用同一 iPhone 样机比例，任务、消息、状态和网址均为虚构数据，不连接真实账户。

README 默认并排展示微信任务列表与任务台对话，窄屏自然换行；审批和任务看板放在可展开区域，避免介绍页过长。

关系图明确表达：

1. 电脑上的 Agent 持有任务、项目、上下文和工具。
2. WeRelay 连接原任务，不成为第二个 Agent。
3. 微信 ClawBot 接收结果、查找任务、回复和处理审批，不需要云服务器。
4. WeRelay 任务台是另一个入口：同一可互访 Wi-Fi 直连电脑；外网访问需自建 HTTPS 服务器和访问认证。
5. 双向箭头表达结果送到手机、指令与审批回到原任务；电脑仍需在线。

图中列出当前公开版本支持的九种 Agent。Pi 等只在官网预览中演示的接入不写成公开版本已经支持。

## Agent 标志

沿用官网已审核的应用标志：Codex 使用 ChatGPT 图标；Grok 使用 Grok 标志，不使用 Grok Bot 图标。Claude Code 使用官网现有标志。其余对象使用同一批官网素材，不手绘替代。

这些标志用于辨认连接对象，权利属于各自品牌，不表示这些品牌为 WeRelay 背书。

## 隐私与变更

- 图中只有固定文案与品牌资产，没有账号、私有任务、凭据、设备地址或日志。
- 新增位图在隐私检查中按文件路径和 SHA-256 登记；图片变化需重新审查并更新登记，不能放开整个图片目录。
- 用户明确批准公开的官网 HTTPS 根地址与产品片的精确公开 URL 只允许出现在指定的介绍文件；其他素材路径、任务链接、API 路径、其他个人域名和真实服务器 IP 仍禁止进入公开文件。
- 本次更新仅涉及品牌素材与说明，不改变软件版本、安装命令和运行行为。
