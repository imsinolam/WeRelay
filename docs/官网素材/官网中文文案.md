# WeRelay 官网文案

[官网与交互演示](https://werelay.sinolin.com/)

本页统一官网与 GitHub 首页的表达。先说明用户能做什么，用演示解释接力；接入限制、安装和服务器操作链接到使用文档，不在首页重复铺开。

## 品牌句

**SAME AGENT. SAME THREAD. ANYWHERE.**

同一个搭档，同一段对话，随处接着来。

## 首屏

**离开电脑，不离开任务。**

电脑继续工作，你在微信接着处理。

主行动：**开始使用**。演示入口：**看看怎么接力**。

## 微信 ClawBot

**任务有进展，微信就知道。**

收到结果，补一句要求，或批准下一步。不用回到电脑前。

- 收到结果：看清是哪项任务、完成了什么。
- 找到任务：发「任务」看列表，加关键词搜索。
- 接着说：发「序号：内容」，继续对应任务。
- 处理审批：按通知里的选项回复数字。
- 继续跑测试：给原任务补一句，让电脑继续。

微信接力无需云服务器。电脑需保持开机、联网并运行 WeRelay。

## WeRelay 任务台

**想看细节，打开任务台。**

从微信里的任务链接，查看完整过程、代码和图片，继续发消息。

演示入口：**完整上下文 / 所有任务 / 切换终端 / 模型设置 / 处理审批**。

模型与推理设置的可用范围、任务空闲条件，以当前公开版本和实际终端配置为准。

## 三种连接场景

| 场景 | 说明 |
| --- | --- |
| 微信接力 | 在外面也能用，无需云服务器。 |
| 同一 Wi-Fi 的任务台 | 手机与电脑网络可互访，即可直连。 |
| 外网任务台 | 需要自建服务器、域名、HTTPS 和访问认证。 |

**需要外网任务台？让 Agent 帮你配置。**

准备服务器与域名，再把配置需求交给 Agent。电脑仍需保持在线。详细操作见[公网 Relay 配置与验收](../使用指南/公网Relay配置与验收.md)。

## 支持与使用边界

**用你熟悉的 Agent。**

不同 Agent 的原任务接入、电脑端可见和实时同步能力不同。首页不把“能连接”写成“任意已打开窗口都能实时同步”，完整说明见[支持范围](../../README.md#支持的-agent-与会话一致性)。

- 手机消息回到电脑上的原任务，不另开替代会话。
- 只中继任务消息、状态、审批和附件，不开放任意电脑端口。
- 电脑离线或任务不可用时，明确提示，不悄悄换成另一条任务。

## 文案与演示原则

- 一个区域只保留一个主标题和一句说明，当前场景才展开操作提示。
- 官网的交互演示使用虚构任务，不连接真实账户。
- 真实聊天、终端和任务台的格式不能为了减字而改得失真。
- 公开版本与预览版本分开说明；关系图只列公开版本已经支持的 Agent。
- 不再使用旧品牌句，不将实现术语放在用户利益之前。
